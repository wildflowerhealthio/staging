Every unit test in src/domain/ runs against FakeGrantStore: the grant store port kept in memory, one map per table, with no diesel and no database. It exists so a test of a rule (a code redeems once, a decision lands once, a revoked session fails closed) reads as the rule, and runs in microseconds. It models the guarantees the domain relies on, not the SQL: each primitive does what its port promises, in plain Rust over the maps. The SQL that keeps the same promises, with real locks and real constraints, is tested in the Persistence part.

This page is also the appendix of the fixtures the crate’s unit tests share, the second half below.

The scopes

A write scope rolls back on Err, as SQLite’s would: it snapshots every map before running the closure and restores them when the closure fails, so a test never sees half of a failed operation. That is the one property of a write scope the fake models. It takes no lock, as the fake is single-threaded, so a race is tested by ordering: read a request, move it with another transition, then write the first.

#![allow(unused)]
fn main() {
fn write<T, E: From<AuthorizationServerError>>(
    &self,
    f: impl FnOnce(&mut Self::Tx<'_>) -> Result<T, E>,
) -> Result<T, E> {
    // No real locking (the fake is single-threaded); the snapshot models
    // the one property the flows rely on, rollback on error, so a
    // partially applied scope never leaks into a later assertion.
    let snapshot = self.tables.snapshot();
    let result = f(&mut FakeGrantTx {
        store: &self.tables,
    });
    if result.is_err() {
        self.tables.restore(snapshot);
    }
    result
}
}

A decision lands once

A replace writes only while the stored request still has the status the transition read it with (the guarded replace).

#![allow(unused)]
fn main() {
fn replace_code_request(
    &mut self,
    read: &CodeRequest,
    changed: &CodeRequest,
) -> Result<bool, AuthorizationServerError> {
    if changed.id != read.id {
        return Err(replaced_by_another(&read.id, &changed.id));
    }
    let mut requests = self.store.code_authorization_requests.borrow_mut();
    let Some(stored) = requests.get_mut(&read.id) else {
        return Ok(false);
    };
    if stored.state.status() != read.state.status() {
        return Ok(false);
    }
    *stored = changed.clone();
    Ok(true)
}
}

#![allow(unused)]
fn main() {
fn replace_user_code_request(
    &self,
    read_id: &str,
    read_status: RequestStatus,
    changed: PolledRequest,
) -> Result<bool, AuthorizationServerError> {
    if changed.id() != read_id {
        return Err(replaced_by_another(read_id, changed.id()));
    }
    let mut requests = self.store.user_code_requests.borrow_mut();
    let Some(stored) = requests.get_mut(read_id) else {
        return Ok(false);
    };
    let stored_as_read = match (&*stored, &changed) {
        (PolledRequest::Device(stored), PolledRequest::Device(_)) => {
            stored.state.status() == read_status
        }
        (PolledRequest::Pairing(stored), PolledRequest::Pairing(_)) => {
            stored.state.status() == read_status
        }
        _ => false,
    };
    if stored_as_read {
        *stored = changed;
    }
    Ok(stored_as_read)
}
}

The Owner is asked about the newest request still waiting

A disabled app’s request is skipped, and an app with no registration is kept with no registered name, as the SQL’s left join to clients does.

Mirrors the adapter’s three reads: the newest candidate from each map (of two started at once, the greater id), keeping the latest by requested_at, and on a tie the code request, then the user-code request.

#![allow(unused)]
fn main() {
fn owner_prompt(
    &mut self,
    now: DateTime<Utc>,
) -> Result<Option<OwnerPrompt>, AuthorizationServerError> {
    let clients = self.store.clients.borrow();
    // Mirrors the SQL: a disabled client's request is skipped, a client
    // with no row's kept.
    let is_candidate = |request: &AuthorizationRequest| {
        request.is_pending_at(now)
            && clients
                .get(request.client_id())
                .is_none_or(|client| client.disabled_at.is_none())
    };
    let newest = |requests: Vec<AuthorizationRequest>| {
        requests
            .into_iter()
            .filter(is_candidate)
            .max_by(|a, b| (a.requested_at(), a.id()).cmp(&(b.requested_at(), b.id())))
    };
    let code = newest(
        self.store
            .code_authorization_requests
            .borrow()
            .values()
            .cloned()
            .map(AuthorizationRequest::Code)
            .collect(),
    );
    let polled = newest(
        self.store
            .user_code_requests
            .borrow()
            .values()
            .cloned()
            .map(AuthorizationRequest::from)
            .collect(),
    );
    let widening = newest(
        self.store
            .session_widening_requests
            .borrow()
            .values()
            .cloned()
            .map(AuthorizationRequest::SessionWidening)
            .collect(),
    );
    let later_of = |first: Option<AuthorizationRequest>,
                    second: Option<AuthorizationRequest>| match (
        first, second,
    ) {
        (Some(first), Some(second)) if second.requested_at() > first.requested_at() => {
            Some(second)
        }
        (Some(first), _) => Some(first),
        (None, second) => second,
    };
    let later = later_of(later_of(code, polled), widening);
    Ok(later.map(|request| {
        // Mirrors the SQL left join: a client with no registration has no
        // registered name.
        let registered_client_name = clients
            .get(request.client_id())
            .map(|client| client.name.clone());
        OwnerPrompt::for_request(&request, registered_client_name)
    }))
}
}

#![allow(unused)]
fn main() {
fn delete_browser_sessions_ended_before(
    &mut self,
    cutoff: DateTime<Utc>,
) -> Result<usize, AuthorizationServerError> {
    let named_by_a_family_alive_at_cutoff: Vec<String> = self
        .store
        .families
        .borrow()
        .values()
        .filter(|family| family.expires_at >= cutoff)
        .filter_map(|family| family.sid.clone())
        .collect();
    let mut sessions = self.store.browser_sessions.borrow_mut();
    let before = sessions.len();
    sessions.retain(|sid, session| {
        let ended_before_cutoff = session.expires_at < cutoff
            || session
                .revoked_at
                .is_some_and(|revoked_at| revoked_at < cutoff);
        !ended_before_cutoff || named_by_a_family_alive_at_cutoff.contains(sid)
    });
    self.store
        .session_shortfall_acknowledgements
        .borrow_mut()
        .retain(|(sid, _)| sessions.contains_key(sid));
    Ok(before - sessions.len())
}
}

Where the fake is looser than SQLite

The fake leaves out what no domain rule rests on, so a test can’t lean on these:

  • No unique constraints. An insert of a repeated key (a sid, a code, a second pending request with the same user_code) overwrites the old entry instead of failing, and the signing-key insert appends.
  • Updates insert. update_authorization_code_grant and update_device_grant write the grant whether or not it was there.
  • Orderings differ. all_grants sorts by grant id, where SQLite orders by granted_at; all_signing_keys keeps insertion order, where SQLite puts the active key first, then orders by kid.
  • No locks. Concurrency is tested in SQLite; the fake only sequences.

fn main() {
pub(crate) fn approve_stored(
    store: &FakeGrantStore,
    id: &str,
    granted_scopes: &[&str],
    requester_name: Option<&str>,
) {
    let mut tx = store.tx();
    let request = tx
        .authorization_request_by_id(id)
        .unwrap()
        .expect("the request is stored");
    let approval = Approval {
        granted_scopes: owned_scopes(granted_scopes),
        patient: None,
    };
    let now = Utc::now();
    let requester_name = requester_name.map(str::to_owned);
    let landed = match request {
        AuthorizationRequest::Code(read) => {
            let approved = read.approve(approval, now).expect("pending");
            tx.replace_code_request(&read, &approved)
        }
        AuthorizationRequest::Device(read) => {
            let approved = read
                .approve(approval, requester_name, now)
                .expect("pending");
            tx.replace_device_request(&read, &approved)
        }
        AuthorizationRequest::Pairing(read) => {
            let approval = PairingApproval {
                granted_scopes: approval.granted_scopes,
            };
            let approved = read
                .approve(approval, requester_name, now)
                .expect("pending");
            tx.replace_pairing_request(&read, &approved)
        }
        AuthorizationRequest::SessionWidening(read) => {
            let approval = SessionWideningApproval {
                granted_scopes: approval.granted_scopes,
            };
            let approved = read.approve(approval, now).expect("pending");
            tx.replace_session_widening_request(&read, &approved)
        }
    };
    assert!(landed.unwrap());
}
