A session widening has two sides on the wire. The browser’s, on the limited page: POST /oauth/authorize/{id}/ask-to-widen files it, and POST /oauth/session-widenings/{id}/poll waits for the Owner and collects the wider session as the browser’s cookie. Both answer only the browser session the request or widening was made in, read from its cookie. The Owner’s, on the widening’s card: GET /authorization/session-widenings/{id}, and its /approve and /deny, gated as the device page’s are.

http::routes::oauth::session_widening

POST /oauth/authorize/{id}/ask-to-widen and POST /oauth/session-widenings/{id}/poll — the limited page’s calls, on its own origin, for a browser whose session holds less than an app’s request asks for: ask the Owner to widen the session by what it lacks, then poll for the decision. The poll that finds the widening approved hands the browser its wider session token as its __Host-browser_session cookie, for the same session.

Each answers only the browser session the request or widening was made in, read from its cookie as the page’s other calls read it; any other browser gets the same 404 as an unknown id. Both are writes, so the host’s cookie→bearer layer refuses one carrying the cookie from anywhere but the server’s origin. Every answer is uncached: an approved poll carries the session’s cookie.

#![allow(unused)]
fn main() {
pub(super) enum SessionWideningStatusBody {
    /// The Owner hasn't decided yet; the page polls again.
    Pending,
    /// The Owner declined: the session is as it was. No cookie is set.
    Declined,
    /// The Owner approved, and this poll collected the wider session: the
    /// response sets its token, for the same session, as the
    /// `__Host-browser_session` cookie, living until the session ends.
    Widened,
    /// The widening expired before the Owner decided, an earlier poll
    /// already collected it, or the session has ended. No cookie is set.
    Expired,
}
}

handle_session_widening_ask

The start limit layer wraps it as AuthorizationStartRoute’s AskToWidenSession.

Ask the Owner to widen this browser’s session by what it lacks of request id, which waits on this browser’s limited page, and raise the Owner’s notification. The widening asks for exactly what the session lacks of the request, and the request keeps waiting on the page as long as the widening waits for the Owner. It spends from the authorization start limit, as a request raised for the Owner does, before anything else is read; a refusal is the limit’s 429.

#![allow(unused)]
fn main() {
pub(super) async fn handle_session_widening_ask(
    _start_limit: StartLimitAskedNow,
    session_widening: Live<LiveSessionWidening>,
    token_verifier: Live<LiveTokenVerifier>,
    headers: HeaderMap,
    Path(id): Path<String>,
) -> Result<Response, AuthorizationServerError> {
    let (_, sid) = requesting_browser_session(&token_verifier, &headers, &id)?;
    let widening_id = session_widening.ask(&id, &sid, Utc::now())?;
    Ok(CacheSuppressed(Json(AskedSessionWideningBody { widening_id })).into_response())
}
}

handle_session_widening_poll

Poll the widening id, asked in this browser’s session. The poll that finds it approved collects the wider session: it sets the session’s new token as the browser’s __Host-browser_session cookie and revokes the token it replaces. A widening of another session’s, or none, is a 404; a store failure, or a token that couldn’t be minted, is a logged 500.

#![allow(unused)]
fn main() {
pub(super) async fn handle_session_widening_poll(
    session_widening: Live<LiveSessionWidening>,
    token_verifier: Live<LiveTokenVerifier>,
    headers: HeaderMap,
    Path(id): Path<String>,
) -> Response {
    let presented_session = match carried_browser_session(&token_verifier, &headers) {
        Ok(Some(presented_session)) => presented_session,
        Ok(None) => {
            return CacheSuppressed(
                AuthorizationServerError::SessionWideningNotFound { id }.into_response(),
            )
            .into_response()
        }
        Err(error) => {
            return InternalError::new("verify a browser session at a widening's poll", error)
                .into_response()
        }
    };
    let response = match session_widening.poll(&id, &presented_session, Utc::now()) {
        Ok(SessionWideningStatus::Widened {
            session_token,
            session_ttl,
        }) => (
            [(
                header::SET_COOKIE,
                browser_session_set_cookie(&session_token, session_ttl),
            )],
            Json(SessionWideningStatusBody::Widened),
        )
            .into_response(),
        Ok(SessionWideningStatus::Pending) => {
            Json(SessionWideningStatusBody::Pending).into_response()
        }
        Ok(SessionWideningStatus::Declined) => {
            Json(SessionWideningStatusBody::Declined).into_response()
        }
        Ok(SessionWideningStatus::Expired) => {
            Json(SessionWideningStatusBody::Expired).into_response()
        }
        Err(SessionWideningPollError::Store(error)) => error.into_response(),
        Err(SessionWideningPollError::Issuance(error)) => {
            InternalError::new("mint a widened browser session's token", error).into_response()
        }
    };
    CacheSuppressed(response).into_response()
}
}

/session-widenings/{id} routes — the Owner-facing consent prompt for a session widening: a paired browser asking, from its limited page, for its browser session to hold more. One module per route (get, approve, deny), each exposing a MethodRouter; the decision result shared with the other consent surfaces (ConsentResult) lives in crate::http::wire_representations, and the consent logic in domain::capabilities. router() is the only path table.

SessionWideningConsent

Body returned when the card loads a pending session widening: the browser that asks, the app it asks for, and the scopes the Owner may grant, which the Owner may only untick.

#![allow(unused)]
fn main() {
pub(crate) struct SessionWideningConsent {
    /// The widening's id, which approve and deny name.
    pub(crate) id: String,
    /// The name of the browser that asks: its session's.
    pub(crate) browser_name: String,
    /// The app whose request the browser's session fell short of.
    pub(crate) client_id: String,
    /// The app's registered name, or its `client_id` when it has no row.
    pub(crate) client_name: String,
    /// What the browser's session lacked of the app's request: the most the
    /// Owner may grant.
    pub(crate) requested_scopes: Vec<String>,
    /// The scopes the card's ticks start from: those of the requested ones
    /// the caller may pass on.
    pub(crate) starting_scopes: Vec<String>,
    /// The approval scopes the caller's own token lacks to approve the
    /// widening (`wildflower/AuthorizationRequest.u`). Empty when it may
    /// approve.
    pub(crate) missing_approval_scopes: Vec<String>,
}
}
