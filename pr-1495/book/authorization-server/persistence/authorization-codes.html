Authorization Codes

Covers authorization-server-rust/src/db/authorization_codes.rs

An authorization code lives in the authorization_codes table from the moment an approval issues it until the app redeems it at /oauth/token, a minute at most. A row is one AuthorizationCode: the code itself as the primary key, and everything it is bound to, the request, the app, the redirect URI, the PKCE challenge, the granted scopes, the patient, the browser session, the issue and expiry instants.

Two rules live in the schema and in one statement:

  • One code per request. A unique index on request_id makes a second code for the same request a hard error, so the status read always finds at most one.
  • A code is redeemed once. Redemption deletes the row and returns it in the same statement, so of two redemptions only one gets it.

The tests draw codes from arb_authorization_code.

authorization_code_by_request_id

When a browser polls the status of a request that has been approved, the status reader reads the code here to build the redirect back to the app. Once the app has redeemed the code, the row is gone and this finds nothing.

Look up the code that was issued for a given request_id, used by the authorize-status poll to build the final redirect URL.

#![allow(unused)]
fn main() {
fn authorization_code_by_request_id(
    &mut self,
    request_id: &str,
) -> Result<Option<AuthorizationCode>, AuthorizationServerError> {
    let conn = &mut *self.conn;
    authorization_codes::table
        .filter(authorization_codes::request_id.eq(request_id))
        .select(AuthorizationCode::as_select())
        .first(conn)
        .optional()
        .map_err(|e| {
            AuthorizationServerError::infrastructure(
                "authorization_code_by_request_id failed",
                e,
            )
        })
}
}

fn main() {
fn corrupt_redirect_uri_is_a_typed_read_error() {
    let store = SqliteGrantStore::open_in_memory().expect("open in-memory store");
    let now = chrono::Utc::now();
    let code = AuthorizationCode {
        code: "the-code".to_string(),
        request_id: "req-1".to_string(),
        client_id: "client-a".to_string(),
        redirect_uri: url::Url::parse("https://example.com/cb").expect("url"),
        code_challenge: "c".repeat(43),
        granted_scopes: vec!["read".to_string()],
        patient: None,
        issued_at: now,
        expires_at: now + chrono::Duration::seconds(60),
        sid: "sid-1".to_owned(),
    };
    store
        .write(|tx| tx.issue_authorization_code(&code))
        .expect("issue");
    let mut conn = store.pool().get().expect("check out a connection");
    diesel::sql_query(
        "UPDATE authorization_codes SET redirect_uri = 'not a url' WHERE code = 'the-code'",
    )
    .execute(&mut conn)
    .expect("tamper the stored row");
    drop(conn);
    assert!(
        store
            .read(|tx| tx.authorization_code_by_request_id("req-1"))
            .is_err(),
        "a corrupt redirect_uri must surface as a typed read error",
    );
}

redeem_authorization_code

Single use rests on this one statement. The row is gone whatever the redemption decides next: a code presented by the wrong app, late, or with the wrong verifier is already spent. What a miss sets off, ending the refresh families an earlier redemption started, is the redemption proof’s.

Atomically read-and-delete the authorization code so a /token redemption either gets the row exactly once or sees None. Wins the RFC 6749 §10.5 single-use race against any concurrent redeemer of the same code — DELETE … RETURNING runs under SQLite’s write lock, so only one caller’s Ok(Some) lands and any racer sees Ok(None).

#![allow(unused)]
fn main() {
fn redeem_authorization_code(
    &mut self,
    code: &str,
) -> Result<Option<AuthorizationCode>, AuthorizationServerError> {
    let conn = &mut *self.conn;
    diesel::delete(authorization_codes::table.find(code))
        .returning(AuthorizationCode::as_returning())
        .get_result(conn)
        .optional()
        .map_err(|e| {
            AuthorizationServerError::infrastructure("redeem_authorization_code failed", e)
        })
}
}

Redemption is destructive and single-winner: the first call returns the row, the second sees None (RFC 6749 §10.5).

#![allow(unused)]
fn main() {
fn redeem_returns_the_row_exactly_once() {
    let store = SqliteGrantStore::open_in_memory().expect("open in-memory store");
    let now = chrono::Utc::now();
    let code = AuthorizationCode {
        code: "the-code".to_string(),
        request_id: "req-1".to_string(),
        client_id: "client-a".to_string(),
        redirect_uri: url::Url::parse("https://example.com/cb").expect("url"),
        code_challenge: "c".repeat(43),
        granted_scopes: vec!["read".to_string()],
        patient: None,
        issued_at: now,
        expires_at: now + chrono::Duration::seconds(60),
        sid: "sid-1".to_owned(),
    };
    store
        .write(|tx| tx.issue_authorization_code(&code))
        .expect("issue");
    let first = store
        .write(|tx| tx.redeem_authorization_code("the-code"))
        .expect("redeem")
        .expect("first redemption wins");
    assert_eq!(first, code);
    assert!(
        store
            .write(|tx| tx.redeem_authorization_code("the-code"))
            .expect("redeem again")
            .is_none(),
        "second redemption must lose",
    );
}
}

delete_authorization_codes_expired_before

The cutoff is the sweep’s, purge_expired with AUTHORIZATION_RETENTION.

Delete every authorization code that expired before cutoff, returning how many rows went. Redemption already deletes a code as it is used (Self::redeem_authorization_code), so this only reaps abandoned ones.

cutoff is the retention cutoff, not now; the window is the caller’s (domain::retention::purge_expired).

#![allow(unused)]
fn main() {
fn delete_authorization_codes_expired_before(
    &mut self,
    cutoff: DateTime<Utc>,
) -> Result<usize, AuthorizationServerError> {
    let conn = &mut *self.conn;
    diesel::delete(
        authorization_codes::table.filter(authorization_codes::expires_at.lt(cutoff)),
    )
    .execute(conn)
    .map_err(|e| {
        AuthorizationServerError::infrastructure(
            "delete_authorization_codes_expired_before failed",
            e,
        )
    })
}
}

The retention delete is a strict < on the cutoff the policy hands down: a code past it goes, one still inside the window stays, and an unexpired code is never in range. Only abandoned codes ever reach here — redemption deletes the row as it consumes it.

#![allow(unused)]
fn main() {
fn delete_expired_codes_respects_the_cutoff() {
    let store = SqliteGrantStore::open_in_memory().expect("open in-memory store");
    let now = chrono::Utc::now();
    let sample = |name: &str, expires_at| AuthorizationCode {
        code: name.to_string(),
        request_id: format!("req-{name}"),
        client_id: "client-a".to_string(),
        redirect_uri: url::Url::parse("https://example.com/cb").expect("url"),
        code_challenge: "c".repeat(43),
        granted_scopes: vec!["read".to_string()],
        patient: None,
        issued_at: now - chrono::Duration::minutes(1),
        expires_at,
        sid: "sid-1".to_owned(),
    };
    for code in [
        sample("old", now - chrono::Duration::days(8)),
        sample("recent", now - chrono::Duration::days(6)),
        sample("live", now + chrono::Duration::minutes(1)),
    ] {
        store
            .write(|tx| tx.issue_authorization_code(&code))
            .expect("issue");
    }

    let purged = store
        .write(|tx| {
            tx.delete_authorization_codes_expired_before(now - chrono::Duration::days(7))
        })
        .expect("delete");

    assert_eq!(purged, 1);
    assert!(store
        .read(|tx| tx.authorization_code_by_request_id("req-old"))
        .expect("query")
        .is_none());
    assert!(store
        .read(|tx| tx.authorization_code_by_request_id("req-recent"))
        .expect("query")
        .is_some());
    assert!(store
        .read(|tx| tx.authorization_code_by_request_id("req-live"))
        .expect("query")
        .is_some());
}
}
