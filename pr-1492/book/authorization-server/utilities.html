The two RFC 4648 alphabets the server needs, named for their exact wire format so they can’t be confused, and the only place a base64 engine is built. crypto_util::sha256

as_base64_no_pad

The at-rest form of a high-entropy secret: a digest can’t be reversed, so a leaked database yields nothing presentable. It is also the PKCE S256 transform, which compute_code_challenge’s test checks against RFC 7636’s example.

SHA-256 of input, base64url-encoded without padding.

pub(crate) fn as_base64_no_pad(input: &[u8]) -> String {
    let mut hasher = Sha256::new();
    hasher.update(input);
    base64::url_safe_no_pad_encode(&hasher.finalize())
}
}

generate_oauth_user_code

The random source is a parameter, so a test can seed it.

Generate a device-flow user code (e.g. BCDF-GHJK) using the unambiguous consonant alphabet.

#![allow(unused)]
fn main() {
pub fn generate_oauth_user_code<R: RngExt + ?Sized>(rng: &mut R) -> String {
    let mut chars =
        std::iter::repeat_with(|| ALPHABET[rng.random_range(0..ALPHABET.len())] as char);
    let dash_count = BLOCK_COUNT - 1;
    let letter_count = BLOCK_COUNT * BLOCK_LENGTH;
    let mut out = String::with_capacity(letter_count + dash_count);
    for block_idx in 0..BLOCK_COUNT {
        if block_idx > 0 {
            out.push('-');
        }
        out.extend((&mut chars).take(BLOCK_LENGTH));
    }
    out
}
}

is_valid_oauth_user_code

Return true if s matches the user-code shape: BLOCK_COUNT blocks of BLOCK_LENGTH ALPHABET chars joined by -.

#![allow(unused)]
fn main() {
pub fn is_valid_oauth_user_code(s: &str) -> bool {
    let mut blocks_seen = 0usize;
    for part in s.split('-') {
        if blocks_seen >= BLOCK_COUNT
            || part.len() != BLOCK_LENGTH
            || !part.bytes().all(|b| ALPHABET.contains(&b))
        {
            return false;
        }
        blocks_seen += 1;
    }
    blocks_seen == BLOCK_COUNT
}
}

verify_client_secret

Verify a presented plaintext secret against a stored argon2id PHC string.

Returns Ok(true) on a match, Ok(false) on a mismatch, and Err only if the stored value cannot be parsed as a PHC hash. The comparison is constant-time internally.

Errors

Returns ClientSecretError::MalformedHash if stored_phc is not a parseable PHC hash string (or verification fails for a non-mismatch reason).

#![allow(unused)]
fn main() {
pub fn verify_client_secret(presented: &str, stored_phc: &str) -> Result<bool, ClientSecretError> {
    let parsed =
        PasswordHash::new(stored_phc).map_err(|e| ClientSecretError::MalformedHash(e.into()))?;
    match Argon2::default().verify_password(presented.as_bytes(), &parsed) {
        Ok(()) => Ok(true),
        Err(argon2::password_hash::Error::PasswordInvalid) => Ok(false),
        Err(e) => Err(ClientSecretError::MalformedHash(e)),
    }
}
}
