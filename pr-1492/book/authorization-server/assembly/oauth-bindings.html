OAuth Bindings

Covers authorization-server-rust/src/live_bindings/oauth.rs

/oauth is the front door: apps, devices and browsers that hold no token for this server yet. No claims unlock its capabilities, so each is a FromState binding, built from the shared state alone and acquired through Live<…>. Where one has a gate, the gate is a proof its method takes, such as an authenticated client at /oauth/token, not the extractor.

Three handles here aren’t for handlers at all. setup_authorization_server gives them to the host, which calls them in-process: one mints launches, one mints sign-in codes, one waits on a consent.

end_signed_in_sessions

The minter also ends the sessions codes signed in, through this run’s store, whichever of the server’s runs minted the codes: the host does once the server’s last launch view closes. Each code is a SameDeviceSignInCode, which holds the code and the set of the run that minted it, but nothing of that run’s store, so a view that outlives its run pins no run’s database. The flow is the same-device session ender.

Withdraw sign_in_codes, and end the sessions they signed browsers in with, by expiring them now in this run’s store, whichever run minted the codes: those browsers’ cookies stop working, and they are sent through sign-in again. Returns how many sessions were ended; a code that signed nobody in, or whose session was ended already, ends nothing. A failure leaves each code holding its session, so ending them can be tried again. It writes to the database, so call it on a blocking thread.

Errors

AuthorizationServerError::Infrastructure on a store failure.

until_settled

After every ping it rereads the request with the store’s is_awaiting_owner (see Owner Prompt), which counts a request still on its limited page as unsettled.

Wait until the request consent names no longer waits for the Owner: decided, expired, or gone. Answers at once for one that already doesn’t. Each read (is_awaiting_owner) runs on a blocking thread.

Errors

AuthorizationServerError::Infrastructure when reading the request fails, or when the authorization server stops before the request settles.

#![allow(unused)]
fn main() {
pub async fn until_settled(&self, consent: ConsentKey) -> Result<(), AuthorizationServerError> {
    let mut pending_consents_recomputed_rx = self.pending_consents_recomputed_rx.clone();
    loop {
        pending_consents_recomputed_rx.borrow_and_update();
        let store = self.store.clone();
        let read_consent = consent.clone();
        let pending = tokio::task::spawn_blocking(move || {
            store.read(|tx| tx.is_awaiting_owner(&read_consent, Utc::now()))
        })
        .await
        .map_err(|error| {
            AuthorizationServerError::infrastructure("reading a pending consent", error)
        })??;
        if !pending {
            return Ok(());
        }
        if pending_consents_recomputed_rx.changed().await.is_err() {
            return Err(AuthorizationServerError::infrastructure(
                "watching a pending consent",
                "the authorization server stopped",
            ));
        }
    }
}
}
