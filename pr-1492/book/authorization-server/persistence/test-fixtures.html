A DateTime<Utc> drawn from a plausible recent epoch window (2000-01-01 to 2065-01-01). Built from a whole millisecond count so the value round-trips through SQLite’s text timestamp encoding without precision loss.

#![allow(unused)]
fn main() {
pub fn arb_timestamp() -> impl Strategy<Value = DateTime<Utc>> {
    let window_start = Utc
        .with_ymd_and_hms(2000, 1, 1, 0, 0, 0)
        .single()
        .expect("valid window start")
        .timestamp_millis();
    let window_end = Utc
        .with_ymd_and_hms(2065, 1, 1, 0, 0, 0)
        .single()
        .expect("valid window end")
        .timestamp_millis();
    (window_start..window_end).prop_map(|millis| {
        Utc.timestamp_millis_opt(millis)
            .single()
            .expect("valid epoch ms")
    })
}
}

A syntactically valid https/http Url, assembled from safe components whose canonical form matches what SQLite stores. The host regex can still emit labels IDNA rejects (e.g. hyphens in positions 3–4, as in xn--), so a filter step drops any candidate the parser refuses.

#![allow(unused)]
fn main() {
pub fn arb_url() -> impl Strategy<Value = Url> {
    (
        prop_oneof![Just("https"), Just("http")],
        "[a-z][a-z0-9-]{0,15}",
        "[a-z]{2,6}",
        prop::option::of("[a-z0-9/_-]{0,24}"),
    )
        .prop_filter_map("host must be IDNA-valid", |(scheme, host, tld, path)| {
            let path = path.unwrap_or_default();
            Url::parse(&format!("{scheme}://{host}.{tld}/{path}")).ok()
        })
}
}

A test-only revoke cascade over the store primitives: deletes the grant of either kind and expires the client’s refresh-token families in one write scope, then answers GrantNotFound when no grant row was deleted. The families are expired even on that miss, and no revocation epoch is bumped, so it is a fixture for these db tests, not GrantsRevoker::revoke.

#![allow(unused)]
fn main() {
fn revoke_grant(
    store: &SqliteGrantStore,
    grant_id: &str,
    client_id: &str,
    now: DateTime<Utc>,
) -> Result<(), AuthorizationServerError> {
    let removed = store.write(|tx| -> Result<bool, AuthorizationServerError> {
        let removed_code = tx.delete_authorization_code_grant(grant_id)?;
        let removed_device = tx.delete_device_grant(grant_id)?;
        tx.expire_refresh_token_families_for_client(client_id, now)?;
        Ok(removed_code || removed_device)
    })?;
    if removed {
        Ok(())
    } else {
        Err(AuthorizationServerError::GrantNotFound {
            id: grant_id.to_owned(),
        })
    }
}
}
