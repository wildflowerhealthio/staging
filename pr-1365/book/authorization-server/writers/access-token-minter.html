Access Token Minter

Covers authorization-server-rust/src/domain/capabilities/writers/access_token_minter.rs

Every access token the server hands out is signed here: an app’s at /oauth/token, a same-device session’s at sign-in, a paired browser’s when its pairing is claimed. What a token claims comes from a token entitlement, never from a list a caller put together, so what a token can be minted for is that enum’s closed set of variants. The lifetime is the caller’s: an app’s ACCESS_TOKEN_TTL, or the lifetime of the browser session the token is minted for.

AccessTokenMinter

Mint access tokens for one server with the signing key that was active when the minter was loaded; the gate is the TokenEntitlement proof mint takes. Loaded and used inside the caller’s scope: reading the key’s private material is the privileged read, and signing is pure computation over it, so a signing failure rolls the scope back with everything else.

#![allow(unused)]
fn main() {
pub(crate) struct AccessTokenMinter<'a> {
    /// The signing key that was active when the minter was loaded, private
    /// material included: every token this minter signs names its `kid`.
    signing_key: SigningKey,
    /// The server's bare origin: both the `iss` and the `aud` claim.
    server_origin: &'a str,
    /// How long each token minted lives, from the instant it is signed.
    ttl: Duration,
}
}

with_active_key

The key is the signing key the server publishes for others to check its tokens. With no active key, nothing can be minted.

A minter holding tx’s active signing key, minting tokens issued by and for server_origin that live for ttl.

Errors

AccessTokenIssuanceError::NoActiveSigningKey when no key can sign; AccessTokenIssuanceError::Store when the key store can’t be read.

#![allow(unused)]
fn main() {
pub(crate) fn with_active_key(
    tx: &mut impl SigningKeysTx,
    server_origin: &'a str,
    ttl: Duration,
) -> Result<Self, AccessTokenIssuanceError> {
    let signing_key = tx
        .active_signing_key()?
        .ok_or(AccessTokenIssuanceError::NoActiveSigningKey)?;
    Ok(AccessTokenMinter {
        signing_key,
        server_origin,
        ttl,
    })
}
}

mint

The token is built by mint_access_token, which adds its own jti and times.

Sign a token carrying exactly the entitlement’s client, scopes, patient and browser session, and return it.

Errors

AccessTokenIssuanceError::Signing on a key-material or encoding failure.

#![allow(unused)]
fn main() {
pub(crate) fn mint(
    &self,
    entitlement: TokenEntitlement<'_>,
) -> Result<String, AccessTokenIssuanceError> {
    Ok(mint_access_token(
        &self.signing_key,
        &NewAccessTokenArgs {
            client_id: entitlement.client_id(),
            scopes: entitlement.token_scopes(),
            ttl: self.ttl,
            issuer: self.server_origin,
            audience: Some(self.server_origin),
            patient: entitlement.patient(),
            sid: entitlement.sid(),
        },
    )?)
}
}

The minted token carries exactly the entitlement’s claims — client, scopes and patient — names the server’s origin as both iss and aud, and verifies against the seeded key.

#![allow(unused)]
fn main() {
fn mint_signs_exactly_the_proofs_claims() {
    let store = FakeGrantStore::default();
    seed_active_signing_key(&store);
    let redeemed = redeemed_code(&store, "client-a", &["patient/Patient.rs", "openid"]);
    let access_token = minter(&store)
        .expect("an active key")
        .mint(TokenEntitlement::AuthorizationCode(&redeemed))
        .expect("mint");
    let keys = store.tx().all_signing_keys().unwrap();
    let claims = verify_access_token(
        &access_token,
        &keys,
        &AccessTokenVerifyOptions {
            expected_issuer: "https://server.example",
            accepted_audiences: &["https://server.example".to_owned()],
        },
    )
    .expect("verifies against the seeded key");
    assert_eq!(claims.subject, "client-a");
    assert_eq!(claims.scope, Some(redeemed.token_scopes().join(" ")));
    assert_eq!(claims.patient.as_deref(), Some("pat-1"));
    assert_eq!(claims.issuer, "https://server.example");
    assert_eq!(claims.audience, vec!["https://server.example".to_owned()]);
}
}
