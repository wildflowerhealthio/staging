Browser Session

Covers authorization-server-rust/src/domain/browser_session.rs

A browser session is a browser the server has let in. It is keyed by its sid, and everything minted while using that browser records the sid: each authorization code, access token and refresh-token family. That is what makes a browser revocable as a unit: revoking the session ends what it earned.

A browser gets a session one of two ways. The Owner’s browser, on the server’s own device, signs in with a same-device sign-in code, and its session lasts eight hours (SAME_DEVICE_SESSION_TTL). Any other browser pairs: it shows a code, the Owner approves it and chooses what it may hold, and its session lasts a day (PAIRED_SESSION_TTL).

A session’s scopes cap what any app requested in it can receive. The Owner may approve an app for more, but the code issued under the session carries only what the session also covers. A browser paired with read-only access earns no app write access, whoever approved the request. This is also why a browser signs in or pairs before it makes app requests: a code is always issued under the session its request was made in.

BrowserSession

One browser session. A session’s scopes cap what any app requested in it can receive: the Owner may approve an app for more, but the code issued under the session carries only what the session also holds. Diesel-mapped 1:1 to the browser_sessions table.

#![allow(unused)]
fn main() {
pub struct BrowserSession {
    /// Primary key — the session's identity, and the `sid` claim of every
    /// authorization code, access token and refresh-token family minted under
    /// it.
    pub sid: String,
    /// How the browser came to hold the session: the Owner's same-device
    /// sign-in, or a pairing the Owner approved.
    pub kind: BrowserSessionKind,
    /// The name the browser was given at pairing; `None` for a same-device session.
    pub name: Option<String>,
    /// The session's grant: the most an app requested in this browser can be
    /// issued.
    pub scopes: Vec<String>,
    /// When the session started: the same-device sign-in, or the pairing
    /// poll that claimed the Owner's approval.
    pub created_at: DateTime<Utc>,
    /// When the session stops letting the browser start things.
    pub expires_at: DateTime<Utc>,
    /// When the session was revoked, ending everything it minted; `None`
    /// while it stands.
    pub revoked_at: Option<DateTime<Utc>>,
    /// When the session was last seen in use: its sign-in, then the server
    /// accepting its cookie (at most once every `LAST_SEEN_RESOLUTION`)
    /// and a refresh-token family that names it rotating.
    pub last_seen_at: DateTime<Utc>,
}
}

#![allow(unused)]
fn main() {
fn a_same_device_session_is_unnamed_and_lasts_its_ttl() {
    let now = Utc::now();
    let session = BrowserSession::new_same_device_session(
        vec!["system/*.cruds".to_owned()],
        Duration::hours(8),
        now,
    );
    assert_eq!(session.kind, BrowserSessionKind::SameDevice);
    assert_eq!(session.name, None);
    assert_eq!(session.expires_at - session.created_at, Duration::hours(8));
    assert_eq!(session.revoked_at, None);
    assert_eq!(session.last_seen_at, now, "signing in is a use");
    assert_ne!(
        session.sid,
        BrowserSession::new_same_device_session(vec![], Duration::hours(8), now).sid,
        "every session gets its own sid"
    );
}
}

is_live

An app’s request is approved into a code only while the session it was made in is live. A request whose session has ended is denied instead, so the app hears access_denied rather than earning a code no live session bounds.

Whether the session is live at now: not revoked, and expires_at after now.

An app’s request is approved into a code only while the session it was made in is live. Otherwise it is denied, so the app hears access_denied rather than earning a code no live session bounds.

#![allow(unused)]
fn main() {
pub fn is_live(&self, now: DateTime<Utc>) -> bool {
    self.revoked_at.is_none() && self.expires_at > now
}
}

#![allow(unused)]
fn main() {
fn a_session_is_live_until_it_expires_or_is_revoked() {
    let now = Utc::now();
    let session = BrowserSession::new_same_device_session(vec![], Duration::hours(8), now);
    assert!(session.is_live(now));
    assert!(!session.is_live(session.expires_at));
    let revoked = BrowserSession {
        revoked_at: Some(now),
        ..session
    };
    assert!(!revoked.is_live(now));
}
}
