Wildflower, Read in Order

Writers

Covers authorization-server-rust/src/domain/capabilities/writers/mod.rs

Some writes hand out authority: approving a request, issuing an authorization code, recording or widening a standing grant, widening an app’s registration, reading a private key to sign a token with, issuing a refresh token, starting a browser session. Every one of them happens in a writer, and every writer method takes an authority proof as the price of admission. A proof can only be had from its one constructor, which runs the check it stands for, so a write that holds the proof is a write whose check ran.

A writer is not a gate of its own. It is built over the caller’s open scope (within(tx)), so what it writes lands with the rest of the operation or not at all, and the gate is the proof each method demands. The capabilities in the next part decide what is being done and obtain the proof; the Grant Store holds the rows. The writers sit between them: the only code that may make the privileged store calls.

  • Request Approver: approves a pending request of any flow, on delegated scopes, and for the code flow issues its code, on delegated scopes or a standing grant, bounded by the requesting browser’s session.
  • Grant Recorder: records the standing grant an approval leaves behind, and registers or widens an app trusted on first use, on delegated scopes.
  • Refresh Family Writer: starts a refresh-token family for a redemption that earns one, and rotates a validated refresh token, expiring the family on a replay.
  • Access Token Minter: reads the active signing key and signs an access token carrying exactly a token entitlement’s claims.
  • Browser Session Writer: stores the session a same-device sign-in or a claimed pairing starts.
  • Test Fixtures: the helpers the writers’ tests share.

domain::capabilities::writers::tests

A privileged write outside the writers fails the unit tests. A new flow that reached around a writer would reach around the proof the writer’s method demands, so the rule is pinned by a source guard rather than left to review. holds

Whether line holds needle, at the start of a name when the needle starts with one. A type named where a type goes, after ->, for or impl, builds nothing.

#![allow(unused)]
fn main() {
fn holds(line: &str, needle: &str) -> bool {
    let starts_a_name = needle.starts_with(|c: char| c.is_alphabetic());
    line.match_indices(needle).any(|(at, _)| {
        if !starts_a_name {
            return true;
        }
        let before = &line[..at];
        let mid_name = before
            .chars()
            .next_back()
            .is_some_and(|c| c.is_alphanumeric() || c == '_' || c == '<');
        let names_a_type = before.trim_end().ends_with("->")
            || before
                .split_whitespace()
                .next_back()
                .is_some_and(|word| word == "for" || word == "impl");
        !mid_name && !names_a_type
    })
}
}

violations

Every privileged call or approval construction in the production lines of source, the file at relative under src/, that its location doesn’t allow, as relative:line needle.

#![allow(unused)]
fn main() {
fn violations(relative: &str, source: &str) -> Vec<String> {
    let mut found = Vec::new();
    let privileged_calls_allowed = ALLOWED_PREFIXES
        .iter()
        .any(|prefix| relative.starts_with(prefix));
    for (n, line) in production_lines(source) {
        if !privileged_calls_allowed {
            for needle in PRIVILEGED_CALLS {
                if holds(&line, needle) {
                    found.push(format!("{relative}:{n} {needle}"));
                }
            }
        }
        for construction in APPROVAL_CONSTRUCTIONS {
            if construction
                .allowed
                .iter()
                .any(|prefix| relative.starts_with(prefix))
            {
                continue;
            }
            let built_in = match line.find("=>") {
                Some(arrow) if construction.read_in_match_arms => &line[arrow + 2..],
                _ => line.as_str(),
            };
            if holds(built_in, construction.needle) {
                found.push(format!("{relative}:{n} {}", construction.needle));
            }
        }
    }
    found
}
}

The guard trips on every approval construction outside its allowed files, and on none inside them; a match arm’s pattern reading a state doesn’t trip it, nor does a name that merely ends like a needle.

#![allow(unused)]
fn main() {
fn the_guard_catches_every_approval_construction_outside_its_files() {
    const FLOW: &str = "domain/capabilities/oauth/flow.rs";
    for construction in APPROVAL_CONSTRUCTIONS {
        let needle = construction.needle;
        let receiver = if needle.starts_with('.') {
            "request"
        } else {
            "flow::"
        };
        let built = format!("fn f() {{\n    let x = {receiver}{needle}y;\n}}\n");
        assert_eq!(
            violations(FLOW, &built).len(),
            1,
            "{needle} outside its files"
        );
        let built_in_an_arm = format!("fn f() {{\n    a => {receiver}{needle}y,\n}}\n");
        assert_eq!(
            violations(FLOW, &built_in_an_arm).len(),
            1,
            "{needle} built in a match arm"
        );
        let read_in_an_arm = format!("fn f() {{\n    {receiver}{needle}y) => a,\n}}\n");
        assert_eq!(
            violations(FLOW, &read_in_an_arm).is_empty(),
            construction.read_in_match_arms,
            "{needle} in a match arm's pattern"
        );
        for prefix in construction.allowed {
            let relative = if prefix.ends_with(".rs") {
                (*prefix).to_owned()
            } else {
                format!("{prefix}inner.rs")
            };
            assert!(
                violations(&relative, &built).is_empty(),
                "{needle} in {relative}"
            );
        }
    }
    assert!(violations(
        FLOW,
        "fn f() -> CodeRequest {\n    let r = ResolvedCodeRequest {\n        a: NotApproved(1),\n    };\n}\nimpl Polled for DeviceRequest {\n}\n",
    )
    .is_empty());
    assert_eq!(
        violations(FLOW, "fn f() {\n    tx.insert_browser_session(&s);\n}\n").len(),
        1
    );
}
}

privileged_store_calls_happen_only_in_writers

Default-safety guard: a privileged store method is called only inside a writer (or the adapter / port / fake / seeding files that define it), and an approved or claimed request is built only where APPROVAL_CONSTRUCTIONS allows. A new flow that reaches around the writers — and so around the proof its method would have demanded — fails here. Comments and unit-test modules are skipped (see production_lines): prose may name the methods, and a test may plant rows to arrange its state. A floor on the number of files checked catches the guard walking an empty tree.

#![allow(unused)]
fn main() {
fn privileged_store_calls_happen_only_in_writers() {
    let src = std::path::Path::new(concat!(env!("CARGO_MANIFEST_DIR"), "/src"));
    let mut checked = 0;
    let mut found = Vec::new();
    for path in rs_files_under(src).expect("enumerate src") {
        let relative = relative_to(&path, src).expect("enumerated under src");
        let source =
            std::fs::read_to_string(&path).unwrap_or_else(|e| panic!("read {relative}: {e}"));
        found.extend(violations(&relative, &source));
        checked += 1;
    }
    assert!(
        found.is_empty(),
        "privileged calls or approval constructions outside where they belong; obtain the \
         authority proof and go through `domain::capabilities::writers`: {found:#?}",
    );
    assert!(
        checked >= 40,
        "only {checked} source files enumerated — did src/ move?",
    );
}
}
