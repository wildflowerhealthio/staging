Request Approver

Covers authorization-server-rust/src/domain/capabilities/writers/request_approver.rs

The request approver moves a pending authorization request to approved, through the flow’s own transition (code, device, pairing) written with the guarded replace. For the code flow it also issues the authorization code the app redeems at /oauth/token.

The scopes a request records are exactly the proof’s, never a list the flow put together. A device request and a browser pairing are approved on delegated scopes: the approver’s ticks, clamped to what it may delegate. A code request may also be approved with no one at the prompt, on a standing grant that already covers it, so it takes either of two proofs.

A code is bound to the browser session the request was made in, not the approver’s. The Owner may approve from another browser, but revoking the browser the app runs in still ends what the code starts, and the code carries only what that browser holds (session_bounded_scopes).

approve_for_code

The session is checked with is_live_at, under the stale-session cutoff, and the code lives for AUTHORIZATION_CODE_TTL.

Approve the pending code-flow request under authority and issue code for it, bound to the request’s client, redirect, and PKCE challenge, to the browser session the request was made in (not the approver’s, so revoking the browser the app runs in ends it), and to the SMART-on-FHIR patient context (if any), expiring AUTHORIZATION_CODE_TTL after now. The flow generates code (a CSPRNG opaque token) so tests can inject a known value.

The request records the authority’s scopes; the code carries only those the request’s browser session also allows (session_bounded_scopes), so a browser paired with less than the Owner holds earns no app more than it holds, whoever approved.

Under a CodeAuthority::StandingGrant, issuing the code also stamps that grant’s last_used_at with now: the grant just stood in for the Owner.

The approval and the code land in the caller’s transaction, which first loads the request’s browser session. A request whose session is no longer live at now under stale_session_cutoff (revoked, expired, stale, or no longer stored) is denied rather than approved (CodeApproval::BrowserSessionEnded), so the client hears access_denied rather than earning a code no live session bounds. A request no longer pending issues nothing (CodeApproval::RequestNotPending); the flow maps that to its own not-found outcome.

#![allow(unused)]
fn main() {
pub(crate) fn approve_for_code(
    &mut self,
    authority: CodeAuthority<'_>,
    request: &CodeRequest,
    patient: Option<&str>,
    code: String,
    stale_session_cutoff: &StaleSessionCutoff,
    now: DateTime<Utc>,
) -> Result<CodeApproval, AuthorizationServerError> {
    let authorized_scopes = authority.authorized_scopes();
    let Some(browser_session) =
        self.tx
            .live_browser_session(&request.sid, stale_session_cutoff, now)?
    else {
        let Ok(denied) = request.to_denied(now) else {
            return Ok(CodeApproval::RequestNotPending);
        };
        return Ok(if self.tx.replace_code_request(request, &denied)? {
            CodeApproval::BrowserSessionEnded
        } else {
            CodeApproval::RequestNotPending
        });
    };
    let approval = Approval {
        granted_scopes: authorized_scopes.to_vec(),
        patient: patient.map(str::to_owned),
    };
    let Ok(approved) = request.to_approved(approval, now) else {
        return Ok(CodeApproval::RequestNotPending);
    };
    if !self.tx.replace_code_request(request, &approved)? {
        return Ok(CodeApproval::RequestNotPending);
    }
    let authorization_code = AuthorizationCode {
        code,
        request_id: request.id.clone(),
        client_id: request.client_id.clone(),
        redirect_uri: request.redirect_uri.clone(),
        code_challenge: request.code_challenge.clone(),
        granted_scopes: session_bounded_scopes(
            authorized_scopes,
            &Grant::parse(&browser_session.scopes),
        ),
        patient: patient.map(str::to_owned),
        issued_at: now,
        expires_at: now + AUTHORIZATION_CODE_TTL,
        sid: browser_session.sid,
    };
    self.tx.issue_authorization_code(&authorization_code)?;
    if let CodeAuthority::StandingGrant(standing_grant_coverage) = authority {
        self.tx
            .stamp_authorization_code_grant_used(standing_grant_coverage.grant_id(), now)?;
    }
    Ok(CodeApproval::Issued(Box::new(authorization_code)))
}
}

#![allow(unused)]
fn main() {
fn approve_for_code_denies_a_request_whose_browser_session_has_ended() {
    let store = FakeGrantStore::default();
    let now = Utc::now();
    let stale_session_cutoff =
        StaleSessionCutoff::new(now - Duration::minutes(30), HashSet::new());
    let standing = BrowserSession::new_same_device_session(vec![], Duration::hours(8), now);
    let revoked = BrowserSession::new_same_device_session(vec![], Duration::hours(8), now);
    let expired = BrowserSession::new_same_device_session(
        vec![],
        Duration::hours(8),
        now - Duration::hours(9),
    );
    let stale = BrowserSession::new_same_device_session(
        vec![],
        Duration::hours(8),
        now - Duration::hours(1),
    );
    for session in [&standing, &revoked, &expired, &stale] {
        store.tx().insert_browser_session(session).unwrap();
    }
    assert!(store
        .tx()
        .revoke_browser_session(&revoked.sid, now)
        .unwrap());

    for (id, sid) in [
        ("req-revoked", revoked.sid.as_str()),
        ("req-expired", expired.sid.as_str()),
        ("req-stale", stale.sid.as_str()),
        ("req-missing", "no-such-sid"),
    ] {
        let pending_request = pending_code_request_in_session(&store, id, sid);
        assert_eq!(
            approve_under(&store, &pending_request, &stale_session_cutoff),
            CodeApproval::BrowserSessionEnded,
            "{id}"
        );
        assert_eq!(stored(&store, id).status(), RequestStatus::Denied, "{id}");
        assert_eq!(
            store.tx().authorization_code_by_request_id(id).unwrap(),
            None,
            "{id}"
        );
    }

    let pending_request =
        pending_code_request_in_session(&store, "req-standing", &standing.sid);
    assert!(matches!(
        approve_under(&store, &pending_request, &stale_session_cutoff),
        CodeApproval::Issued(issued_code) if issued_code.sid == standing.sid
    ));
}
}

#![allow(unused)]
fn main() {
pub(crate) fn approve_session_widening(
    &mut self,
    delegated_scopes: &DelegatedScopes,
    request: &SessionWideningRequest,
    stale_session_cutoff: &StaleSessionCutoff,
    now: DateTime<Utc>,
) -> Result<SessionWideningOutcome, AuthorizationServerError> {
    let Some(browser_session) =
        self.tx
            .live_browser_session(&request.sid, stale_session_cutoff, now)?
    else {
        let Ok(denied) = request.to_denied(now) else {
            return Ok(SessionWideningOutcome::RequestNotPending);
        };
        return Ok(
            if self.tx.replace_session_widening_request(request, &denied)? {
                SessionWideningOutcome::BrowserSessionEnded
            } else {
                SessionWideningOutcome::RequestNotPending
            },
        );
    };
    let approval = SessionWideningApproval {
        granted_scopes: delegated_scopes.scopes().to_vec(),
    };
    let Ok(approved) = request.to_approved(approval, now) else {
        return Ok(SessionWideningOutcome::RequestNotPending);
    };
    if !self
        .tx
        .replace_session_widening_request(request, &approved)?
    {
        return Ok(SessionWideningOutcome::RequestNotPending);
    }
    let widened_session_scopes = wildflowerhealthio_scopes::widened_scopes(
        &browser_session.scopes,
        delegated_scopes.scopes(),
    );
    if !self
        .tx
        .update_browser_session_scopes(&browser_session.sid, &widened_session_scopes)?
    {
        // The row was read live in this same scope, so a miss is the
        // store breaking its word: fail, rolling the approval back.
        return Err(AuthorizationServerError::Infrastructure {
            context: "approve_session_widening: the live session's row wasn't updated",
            source: format!("no browser session {}", browser_session.sid),
        });
    }
    self.tx
        .forget_session_shortfall_acknowledgements(&browser_session.sid)?;
    Ok(SessionWideningOutcome::Widened)
}
}
