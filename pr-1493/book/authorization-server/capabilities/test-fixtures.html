Test Fixtures

The helpers the Capabilities part’s unit tests build their capabilities and values with, by the page whose tests use them. They build on the in-memory test fake and its shared fixtures (a client, a code request, a device request, a browser pairing, a seeded browser session, a recording republish port); the rest sit in the test module they serve.

Several test modules name their helpers alike (SERVER_ORIGIN, authenticated, claims); where a name repeats, the later ones are shown as plain excerpts with their doc comments kept.
