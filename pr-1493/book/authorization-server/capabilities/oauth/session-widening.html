Session Widening

Covers authorization-server-rust/src/domain/capabilities/oauth/session_widening.rs

SessionWidening — the limited page’s ask to widen the browser’s own session, and its poll for the Owner’s decision. A browser whose session holds less than an app’s request asks for can ask the Owner, from that request’s limited page, to widen the session by what it lacks (ask); the Owner decides it on its own consent card (ConsentDecider), which widens the session’s row on approval. The page’s poll (poll) then claims the approval once, minting the browser a session token that carries the wider scopes for the same session, and revoking the token it replaces.

Both answer only the browser session the widening is for, read from its cookie, so a leaked id asks and collects nothing. Re-pairing is not how a session grows: it would end the session, and everything minted under it.

The ask is bound to the limited page’s request: it widens by exactly that request’s session_shortfall against the session’s row, and keeps the request waiting there until the widening’s approval can no longer be collected (extend_limited_page_wait_until), so the browser can go on with it once the Owner has decided. An ask is answered once: asking again while a widening of the same session, app and scopes waits for the Owner answers that widening, so a retried ask neither notifies the Owner again nor spends the start limit. The Owner decides on the widening’s card, through the session widening consents, which widen the session’s row. The poll then claims the approval under a claimed session widening and revokes the token the new one replaces, from a short grace on: the browser’s requests already in flight with the old cookie still land, so the host’s cookie layer never answers one by clearing the wider cookie the browser was just handed.

    /// The Owner hasn't decided yet.
    Pending,
    /// The Owner declined: the session is as it was.

ask

Ask the Owner to widen the browser session sid by what it lacks of the code request code_request_id, which waits on that browser’s limited page. The widening asks for exactly the request’s session_shortfall against the session as its row stands, never for anything the browser names. It waits for the Owner for AUTHORIZATION_REQUEST_TTL, and the code request waits on its limited page until the widening’s approval can no longer be collected and gone on with (asking_code_request_expires_at).

Asking again while a widening of this session for the same app and the same scopes still waits for the Owner answers that widening: the Owner isn’t told again, the start limit isn’t asked, and the code request waits no longer than that widening lets it. Only a new widening asks may_ask_owner — the authorization start limit, which a widening spends from as any request raised for the Owner does — and republishes the Owner prompt once it commits.

Errors

AuthorizationServerError::AuthorizationRequestNotFound when no request of this session’s waits on its limited page with that id, as the page’s other calls answer, or when there is nothing to ask for: a session that has ended, or holds all the request asks, or is the Owner’s own same-device session (which holds all the Owner could grant). A store failure.

#![allow(unused)]
fn main() {
pub(crate) fn ask(
    &self,
    code_request_id: &str,
    sid: &str,
    may_ask_owner: impl FnOnce() -> bool,
    now: DateTime<Utc>,
) -> Result<SessionWideningAsk, AuthorizationServerError> {
    let not_found = || AuthorizationServerError::AuthorizationRequestNotFound {
        id: code_request_id.to_owned(),
    };
    let asked = self.store.write(|tx| {
        let code_request =
            load_code_request_awaiting_limited_page(tx, code_request_id, sid, now)?;
        let browser_session = tx
            .live_browser_session(sid, &self.stale_session_cutoff, now)?
            .filter(|browser_session| browser_session.kind == BrowserSessionKind::Paired)
            .ok_or_else(not_found)?;
        let Some(browser_name) = browser_session.name else {
            return Err(not_found());
        };
        let missing_scopes = session_shortfall(
            &code_request.requested_scopes,
            &Grant::parse(&browser_session.scopes),
        );
        if missing_scopes.is_empty() {
            return Err(not_found());
        }
        let already_asked = tx
            .pending_session_widening_requests_for_session(sid, now)?
            .into_iter()
            .find(|widening_request| {
                widening_request.client_id == code_request.client_id
                    && widening_request.requested_scopes == missing_scopes
            });
        let (widening_request, filed) = match already_asked {
            Some(widening_request) => (widening_request, false),
            None if !may_ask_owner() => return Ok(None),
            None => {
                let widening_request = SessionWideningRequest::new(
                    NewSessionWideningRequestArgs {
                        id: Uuid::new_v4().to_string(),
                        sid: sid.to_owned(),
                        client_id: code_request.client_id.clone(),
                        browser_name,
                        requested_scopes: missing_scopes,
                        ttl: AUTHORIZATION_REQUEST_TTL,
                    },
                    now,
                );
                tx.insert_session_widening_request(&widening_request)?;
                (widening_request, true)
            }
        };
        let waiting_longer = code_request
            .extend_limited_page_wait_until(
                widening_request.asking_code_request_expires_at(),
                now,
            )
            .map_err(|_| not_found())?;
        if waiting_longer != code_request
            && !tx.replace_code_request(&code_request, &waiting_longer)?
        {
            return Err(not_found());
        }
        Ok(Some((widening_request.id, filed)))
    })?;
    let Some((widening_id, filed)) = asked else {
        return Ok(SessionWideningAsk::StartLimited);
    };
    if filed {
        self.owner_approval.republish_active();
    }
    Ok(SessionWideningAsk::Asked { widening_id })
}
}

poll

Poll the widening widening_id at now, for the browser whose session cookie carries presented_session. The whole poll is one write scope:

  • pending and unexpired: Pending;
  • denied: Declined;
  • approved and unexpired, its session still live: the first poll claims it and mints the session’s new token, together or not at all; Widened with the token;
  • anything else (expired, claimed already, its session ended): Expired.

Once a claim has committed, the presented token is revoked from REPLACED_SESSION_TOKEN_GRACE on, so the narrower token it replaces stops working once the browser’s requests already in flight with it have landed; revoking is best-effort, and a failure is logged.

Errors

AuthorizationServerError::SessionWideningNotFound when no widening asked in the presented session has the id; a store or minting failure.

#![allow(unused)]
fn main() {
pub(crate) fn poll(
    &self,
    widening_id: &str,
    presented_session: &VerifiedClaims,
    now: DateTime<Utc>,
) -> Result<SessionWideningStatus, SessionWideningPollError> {
    let polled = self.store.write(|tx| {
        let widening_request = tx
            .session_widening_request_by_id(widening_id)?
            .filter(|widening_request| {
                presented_session.sid.as_deref() == Some(widening_request.sid.as_str())
            })
            .ok_or_else(|| AuthorizationServerError::SessionWideningNotFound {
                id: widening_id.to_owned(),
            })?;
        match widening_request.state {
            PolledState::Pending if widening_request.is_pending_at(now) => {
                Ok(PolledWidening::Answered(SessionWideningStatus::Pending))
            }
            PolledState::Denied => {
                Ok(PolledWidening::Answered(SessionWideningStatus::Declined))
            }
            PolledState::Approved(_) => self.claim_widened_session(tx, &widening_request, now),
            PolledState::Pending | PolledState::Claimed(_) => {
                Ok(PolledWidening::Answered(SessionWideningStatus::Expired))
            }
        }
    })?;
    match polled {
        PolledWidening::Answered(status) => Ok(status),
        PolledWidening::Claimed {
            session_token,
            session_ttl,
        } => {
            self.revoke_replaced_token(presented_session, now);
            Ok(SessionWideningStatus::Widened {
                session_token,
                session_ttl,
            })
        }
    }
}
}

fn main() {
fn claim_widened_session(
    &self,
    tx: &mut impl GrantTx,
    widening_request: &SessionWideningRequest,
    now: DateTime<Utc>,
) -> Result<PolledWidening, SessionWideningPollError> {
    let Some(claimed_widening) =
        ClaimedSessionWidening::claim(tx, widening_request, &self.stale_session_cutoff, now)?
    else {
        return Ok(PolledWidening::Answered(SessionWideningStatus::Expired));
    };
    let session_ttl = claimed_widening.session().expires_at - now;
    let session_token =
        AccessTokenMinter::with_active_key(tx, &self.server_origin, session_ttl)
            .and_then(|minter| {
                minter.mint(TokenEntitlement::SessionWidening(&claimed_widening))
            })
            .map_err(SessionWideningPollError::Issuance)?;
    Ok(PolledWidening::Claimed {
        session_token,
        session_ttl,
    })
}
