Standing Grant

Covers authorization-server-rust/src/domain/authority/standing_grant.rs

Once the Owner has approved an app, its next request for the same thing shouldn’t ask again. A standing grant records what the Owner approved for an app at one redirect, and /oauth/authorize may issue a code on it with nobody asked. That fast path is a code issued with no human in the loop, so it needs a proof of its own.

The Grant page lists what it takes for a grant to skip the Owner. This proof holds the first two: the request changes nothing in the app’s registration, and the standing grant covers every scope it asks for. However well an old grant covers a request from a new app, at a new redirect or for a new scope, the Owner hasn’t seen that combination, so it goes back to them. The other two, the browser session and the launch’s patient, are checked by /oauth/authorize beside the proof: it takes the fast path only when the request admits the grant’s patient, and the code is still bounded by the browser session.

A grant that covers only some of the scopes isn’t a proof, but the Owner’s earlier yes still counts: the consent card opens with those scopes already ticked.

GrantCoverage

How far a standing grant covers a request. Only Full is a proof; the other two carry what the consent prompt pre-ticks.

#![allow(unused)]
fn main() {
pub(crate) enum GrantCoverage {
    /// No standing grant for this `(client, redirect_uri)`, or the request is
    /// outside the registration.
    Uncovered,
    /// A grant covers some of the requested scopes — the prompt pre-ticks them,
    /// the Owner decides the rest.
    Partial {
        /// The requested scopes the grant covers, in request order; the
        /// parked request records them so the consent card opens with them
        /// ticked.
        pre_approved_scopes: Vec<String>,
    },
    /// Every requested scope is covered: the fast path.
    Full(StandingGrantCoverage),
}
}

resolve

The one constructor of the proof. /oauth/authorize resolves it in the scope that parks the request, and again when the browser goes on past the limited page.

Look up the standing grant for (requested_client_id, requested_redirect_uri) and compute which of requested_scopes it covers. A request that would change its registration never resolves past GrantCoverage::Uncovered, whatever the grant says. /oauth/authorize resolves it in the scope that parks the request, and again when the browser goes on past the limited page.

“Covers” is wildflowerhealthio_scopes::allowed_scope_covers, not string equality: a standing grant is a set of permissions, so patient/*.cruds answers for a later patient/Observation.r, and a grant the approval collapsed (.r + .s recorded as .rs) still answers for either half.

#![allow(unused)]
fn main() {
pub(crate) fn resolve(
    tx: &mut impl GrantsTx,
    presented_client_change: &PresentedClientChange,
    requested_client_id: &str,
    requested_redirect_uri: &Url,
    requested_scopes: &[String],
) -> Result<GrantCoverage, AuthorizationServerError> {
    if presented_client_change.would_change_registration() {
        return Ok(GrantCoverage::Uncovered);
    }
    let Some(grant) =
        tx.grant_by_client_and_redirect(requested_client_id, requested_redirect_uri)?
    else {
        return Ok(GrantCoverage::Uncovered);
    };
    let pre_approved_scopes: Vec<String> = requested_scopes
        .iter()
        .filter(|requested| {
            grant.scopes.iter().any(|granted| {
                wildflowerhealthio_scopes::allowed_scope_covers(granted, requested)
            })
        })
        .cloned()
        .collect();
    // `pre_approved_scopes` is `requested_scopes` filtered, so equal lengths
    // means nothing was filtered out.
    if pre_approved_scopes.len() == requested_scopes.len() {
        Ok(GrantCoverage::Full(StandingGrantCoverage {
            grant_id: grant.id,
            covered_scopes: pre_approved_scopes,
            patient: grant.patient,
        }))
    } else {
        Ok(GrantCoverage::Partial {
            pre_approved_scopes,
        })
    }
}
}

#![allow(unused)]
fn main() {
fn full_coverage_is_a_proof_carrying_the_requested_scopes() {
    let store = store_with_grant(&["patient/*.cruds", "openid"], Some("pat-1"));
    let coverage = GrantCoverage::resolve(
        &mut store.tx(),
        &PresentedClientChange::NoChange,
        "client",
        &redirect(),
        &owned_scopes(&["patient/Observation.r", "openid"]),
    )
    .unwrap();
    let GrantCoverage::Full(proof) = coverage else {
        panic!("expected full coverage");
    };
    assert_eq!(proof.covered_scopes(), ["patient/Observation.r", "openid"]);
    assert_eq!(proof.patient(), Some("pat-1"));
}
}

fn main() {
fn unregistered_requests_and_missing_grants_never_prove() {
    let store = store_with_grant(&["patient/*.cruds", "openid"], None);
    let requested = owned_scopes(&["openid"]);
    let outside = GrantCoverage::resolve(
        &mut store.tx(),
        &PresentedClientChange::WouldCreate,
        "client",
        &redirect(),
        &requested,

    assert!(matches!(outside, GrantCoverage::Uncovered));

pub(crate) fn pre_approved_scopes(&self) -> &[String] {
    match self {
        GrantCoverage::Uncovered => &[],
        GrantCoverage::Partial {
            pre_approved_scopes,
        } => pre_approved_scopes,
        GrantCoverage::Full(full) => &full.covered_scopes,

StandingGrantCoverage

Proof that a standing grant covers every scope of a registered request. Carries those scopes (the requested set, verbatim) and the grant’s patient context; the fields are private and only GrantCoverage::resolve builds one.

#![allow(unused)]
fn main() {
pub(crate) struct StandingGrantCoverage {
    /// The standing grant that covers the request; a code issued under this
    /// proof stamps that grant's `last_used_at`.
    grant_id: String,
    /// The requested scopes, verbatim and all of them: what the request
    /// records and the code may carry, before the browser session bounds it.
    covered_scopes: Vec<String>,
    /// The SMART-on-FHIR patient context the grant was approved with, which
