Two flows ask from something that can’t show the Owner a consent card itself, and so wait by polling:

  • A device request (RFC 8628): a TV or a watch asks for a token, shows its user a short user_code, and polls /oauth/token with its device_code until the Owner decides.
  • A browser pairing: a browser that isn’t on the server’s own device asks for a browser session at /oauth/pair, shows a user_code, and polls with its pairing code. Pairing is no OAuth grant: its claim starts a paired session, and nothing is redeemed at /oauth/token.

Both are decided at the server’s device page, where the Owner enters or confirms the user_code. The key the poll uses, the device_code or the pairing code, is a 256-bit secret only the poller holds; the user_code is short enough to type, and only finds the request for the Owner.

stateDiagram-v2
    [*] --> Pending: new
    Pending --> Pending: stamp_poll
    Pending --> Approved: approve
    Pending --> Denied: deny
    Approved --> Claimed: claim, by the next poll

An approval is redeemed once. The poll after the Owner approves claims the request; a second claim finds it claimed and gets nothing. A claimed request keeps its approval, and an approved request past its expiry can’t be claimed. A poll is stamped, so the next one can be told to slow down when it comes sooner than DEVICE_CODE_POLL_INTERVAL after it. A stamp leaves the request pending, so an approval read before the stamp still lands after it (the guarded replace).

Polled

What a device request and a browser pairing share: the code the Owner enters, the poll that waits on the decision, and the claim that redeems it.

#![allow(unused)]
fn main() {
pub trait Polled: Sized {
    /// What the Owner's approval carries for this flow.
    type Approval: Clone;

    /// The code the device page looks the request up by, which the Owner
    /// enters or confirms there.
    fn user_code(&self) -> &str;

    /// The last poll, for the slow-down; `None` before the first.
    fn last_polled_at(&self) -> Option<DateTime<Utc>>;

    /// The instant the request stops waiting for a decision.
    fn expires_at(&self) -> DateTime<Utc>;

    /// Where the request stands.
    fn state(&self) -> &PolledState<Self::Approval>;

    /// The approved request as it would be once claimed at `now`: the poll
    /// that redeems the Owner's approval, which may happen once. Stores
    /// nothing.
    ///
    /// # Errors
    ///
    /// [`NotClaimable`] for a request not approved, or past its expiry.
    fn to_claimed(&self, now: DateTime<Utc>) -> Result<Self, NotClaimable>;

    /// Whether the request is past its expiry at `now`.
    fn is_expired_at(&self, now: DateTime<Utc>) -> bool {
        self.expires_at() <= now
    }

    /// Whether the request waits for the Owner's decision at `now`: pending
    /// and unexpired.
    fn is_pending_at(&self, now: DateTime<Utc>) -> bool {
        matches!(self.state(), PolledState::Pending) && !self.is_expired_at(now)
    }

    /// Whether a poll at `now` comes sooner than [`DEVICE_CODE_POLL_INTERVAL`]
    /// after the last one, which answers `slow_down` (RFC 8628 §3.5).
    fn is_polled_too_soon_at(&self, now: DateTime<Utc>) -> bool {
        self.last_polled_at()
            .is_some_and(|last_polled_at| now - last_polled_at < DEVICE_CODE_POLL_INTERVAL)
    }
}
}

fn main() {
pub enum PolledState<A> {
    /// Waiting for the Owner's decision, until it expires.
    Pending,
    /// The Owner approved it; the next poll claims the approval.
    Approved(A),
    /// The Owner declined it.
    Denied,
    /// A poll redeemed the approval, once (RFC 8628 §3.4 single use). It keeps
    /// the approval it redeemed.

}
}

claimed_state

The claimed state of request at now: its approval, redeemed. The flows’ Polled::to_claimed build on it.

#![allow(unused)]
fn main() {
pub(super) fn claimed_state<P: Polled>(
    request: &P,
    now: DateTime<Utc>,
) -> Result<PolledState<P::Approval>, NotClaimable> {
    match request.state() {
        PolledState::Approved(approval) if !request.is_expired_at(now) => {
            Ok(PolledState::Claimed(approval.clone()))
        }
        _ => Err(NotClaimable),
    }
}
}
