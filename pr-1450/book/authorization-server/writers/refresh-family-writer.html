Refresh Family Writer

Covers authorization-server-rust/src/domain/capabilities/writers/refresh_family_writer.rs

A refresh token is a standing credential: with it, an app gets fresh access tokens long after the person who approved it has left. Refresh tokens come in families. A family starts with one token when a grant is redeemed, and each refresh consumes the token presented and adds its successor, so one token in a family is live at a time. The family holds what every token in it is good for: the app, the scopes, the patient, the deadline.

The refresh-family writer starts families and rotates tokens. Both take a redemption proof: a GrantRedemption to start a family, so a refresh token is only ever minted for scopes a consumed code or a claimed device request recorded; a ValidatedRefreshToken to rotate one, so a token is only ever rotated within a family that validated for the app presenting it.

A rotation is also a use. An app refreshing is its browser session in use, so the session’s last_seen_at moves, and a device refreshing is its pairing in use, so the device grant that earned the family is stamped used. A code grant isn’t stamped on a refresh: it is used when it stands in for the Owner at /oauth/authorize, which the request approver stamps.

start_family

A family comes only with offline_access: the token exchange asks the redemption’s is_refresh_token_earned first, and the writer itself doesn’t ask. The family’s deadline is REFRESH_TOKEN_FAMILY_TTL from now, and rotation never extends it.

Mint a new family with its first token and return the token’s plaintext. The caller checks is_refresh_token_earned first. The family records the redemption’s scopes and patient verbatim, the code it consumed (so a replay of that code can revoke the lineage), the standing grant behind it, and the browser session it was made under (so revoking that session ends it).

#![allow(unused)]
fn main() {
pub(crate) fn start_family(
    &mut self,
    redemption: GrantRedemption<'_>,
    now: DateTime<Utc>,
) -> Result<String, AuthorizationServerError> {
    let plaintext = generate_refresh_token();
    let family = RefreshTokenFamily {
        family_id: Uuid::new_v4().to_string(),
        client_id: redemption.client_id().to_owned(),
        scopes: redemption.granted_scopes().to_vec(),
        patient: redemption.patient().map(str::to_owned),
        issued_at: now,
        expires_at: now + REFRESH_TOKEN_FAMILY_TTL,
        authorization_code_hash: redemption.authorization_code().map(token_storage_hash),
        grant_id: redemption.grant_id().map(str::to_owned),
        sid: redemption.sid().map(str::to_owned),
    };
    let first_token = RefreshToken {
        token_hash: token_storage_hash(&plaintext),
        family_id: family.family_id.clone(),
        issued_at: now,
        consumed_at: None,
    };
    self.tx.insert_refresh_token_family_row(&family)?;
    self.tx.insert_refresh_token(&first_token)?;
    Ok(plaintext)
}
}

rotate

The consume is the single-use claim (consume_refresh_token).

Consume the presented token and, only if that consume won, insert its successor and return the successor’s plaintext. A family made under a browser session moves that session’s last_seen_at to now: an app refreshing is the session in use. A family a device grant earned stamps that grant’s last_used_at with now: a device refreshing is the pairing in use.

A refusal is the inner Err, so the caller’s scope keeps what it wrote: InvalidGrantReason::RefreshTokenReplayed when the token had already been consumed — a leak or a badly broken client, either way an unsafe lineage, so the whole family is expired at now first; and InvalidGrantReason::RefreshTokenVanished when it disappeared between validation and rotation (nothing to revoke).

Errors

AuthorizationServerError::Infrastructure on a store failure.

#![allow(unused)]
fn main() {
pub(crate) fn rotate(
    &mut self,
    validated_refresh_token: &ValidatedRefreshToken,
    now: DateTime<Utc>,
) -> Result<Result<String, TokenExchangeError>, AuthorizationServerError> {
    let family_id = validated_refresh_token.family_id();
    match consume_refresh_token(self.tx, validated_refresh_token.presented_hash(), now)? {
        RefreshTokenConsumeOutcome::Consumed => {
            let successor = generate_refresh_token();
            self.tx.insert_refresh_token(&RefreshToken {
                token_hash: token_storage_hash(&successor),
                family_id: family_id.to_owned(),
                issued_at: now,
                consumed_at: None,
            })?;
            if let Some(sid) = validated_refresh_token.sid() {
                self.tx.touch_browser_session_last_seen(sid, now, now)?;
            }
            if let Some(grant_id) = validated_refresh_token.device_grant_id() {
                self.tx.stamp_device_grant_used(grant_id, now)?;
            }
            Ok(Ok(successor))
        }
        RefreshTokenConsumeOutcome::Replayed => {
            self.tx.expire_refresh_token_family(family_id, now)?;
            Ok(Err(TokenExchangeError::InvalidGrant(
                InvalidGrantReason::RefreshTokenReplayed {
                    family_id: family_id.to_owned(),
                    client_id: validated_refresh_token.client_id().to_owned(),
                },
            )))
        }
        RefreshTokenConsumeOutcome::NotFound => Ok(Err(TokenExchangeError::InvalidGrant(
            InvalidGrantReason::RefreshTokenVanished {
                family_id: family_id.to_owned(),
            },
        ))),
    }
}
}

fn main() {
fn rotate_consumes_then_replay_expires_the_family() {
    let store = FakeGrantStore::default();
    seed_fixture_browser_session(&store);
    let mut tx = store.tx();
    let mut writer = RefreshFamilyWriter::within(&mut tx);
    let now = Utc::now();
    let redeemed_code = redeemed_code(&store, "client", &["offline_access"]);
    let first = writer
        .start_family(GrantRedemption::AuthorizationCode(&redeemed_code), now)
        .unwrap();
    let presented = validated(&store, &first);

    let successor = writer
        .rotate(&presented, now)
        .unwrap()
        .expect("first rotation rotates");
    assert!(store
        .tx()
        .refresh_token_with_family_by_hash(&token_storage_hash(&successor))
        .unwrap()
        .is_some());

    assert!(matches!(
        writer.rotate(&presented, now).unwrap(),
        Err(TokenExchangeError::InvalidGrant(
            InvalidGrantReason::RefreshTokenReplayed { .. }
        ))
    ));
    let (_, family) = store
        .tx()
        .refresh_token_with_family_by_hash(&token_storage_hash(&successor))
        .unwrap()
        .unwrap();
    assert_eq!(family.expires_at, now, "the whole family is expired");

#![allow(unused)]
fn main() {
fn rotate_marks_the_family_s_browser_session_seen() {
    use crate::domain::browser_session::BrowserSession;

    let store = FakeGrantStore::default();
    let mut tx = store.tx();
    let mut writer = RefreshFamilyWriter::within(&mut tx);
    let signed_in_at = Utc::now() - chrono::Duration::hours(1);
    let session = BrowserSession::new_same_device_session(
        vec![],
        chrono::Duration::hours(8),
        signed_in_at,
    );
    store.tx().insert_browser_session(&session).unwrap();
    for (family_id, sid) in [("under-session", Some(&session.sid)), ("no-session", None)] {
        store
            .tx()
            .insert_refresh_token_family_row(&RefreshTokenFamily {
                family_id: family_id.to_owned(),
                client_id: "client".to_owned(),
                scopes: vec!["offline_access".to_owned()],
                patient: None,
                issued_at: signed_in_at,
                expires_at: signed_in_at + REFRESH_TOKEN_FAMILY_TTL,
                authorization_code_hash: None,
                grant_id: None,
                sid: sid.cloned(),
            })
            .unwrap();
        store
            .tx()
            .insert_refresh_token(&RefreshToken {
                token_hash: token_storage_hash(family_id),
                family_id: family_id.to_owned(),
                issued_at: signed_in_at,
                consumed_at: None,
            })
            .unwrap();
    }
    let last_seen = || {
        store
            .tx()
            .browser_session_by_sid(&session.sid)
            .unwrap()
            .unwrap()
            .last_seen_at
    };

    let rotated_at = Utc::now();
    writer
        .rotate(&validated(&store, "no-session"), rotated_at)
        .unwrap()
        .expect("rotates");
    assert_eq!(
        last_seen(),
        signed_in_at,
        "a family with no session touches none"
    );

    writer
        .rotate(&validated(&store, "under-session"), rotated_at)
        .unwrap()
        .expect("rotates");
    assert_eq!(last_seen(), rotated_at);
}
}

#![allow(unused)]
fn main() {
fn rotate_stamps_the_device_grant_that_earned_the_family() {
    use crate::domain::grant::{DeviceGrant, Grant};

    let store = FakeGrantStore::default();
    let issued_at = Utc::now() - chrono::Duration::hours(1);
    store
        .tx()
        .create_device_grant(&DeviceGrant {
            id: "device-grant".to_owned(),
            client_id: "client".to_owned(),
            scopes: vec!["offline_access".to_owned()],
            granted_at: issued_at,
            last_used_at: None,
            patient: None,
            device_name: "Reception iPad".to_owned(),
        })
        .unwrap();
    store
        .tx()
        .create_authorization_code_grant(&code_grant("code-grant", "client"))
        .unwrap();
    for (family_id, grant_id, authorization_code_hash) in [
        ("device-family", "device-grant", None),
        (
            "code-family",
            "code-grant",
            Some(token_storage_hash("code")),
        ),
    ] {
        store
            .tx()
            .insert_refresh_token_family_row(&RefreshTokenFamily {
                family_id: family_id.to_owned(),
                client_id: "client".to_owned(),
                scopes: vec!["offline_access".to_owned()],
                patient: None,
                issued_at,
                expires_at: issued_at + REFRESH_TOKEN_FAMILY_TTL,
                authorization_code_hash,
                grant_id: Some(grant_id.to_owned()),
                sid: None,
            })
            .unwrap();
        store
            .tx()
            .insert_refresh_token(&RefreshToken {
                token_hash: token_storage_hash(family_id),
                family_id: family_id.to_owned(),
                issued_at,
                consumed_at: None,
            })
            .unwrap();
    }
    let last_used_at = |id: &str| match store.tx().grant_by_id(id).unwrap() {
        Some(Grant::AuthorizationCode(grant)) => grant.last_used_at,
        Some(Grant::DeviceCode(grant)) => grant.last_used_at,
        None => panic!("grant {id} present"),
    };

    let rotated_at = Utc::now();
    for family_id in ["device-family", "code-family"] {
        RefreshFamilyWriter::within(&mut store.tx())
            .rotate(&validated(&store, family_id), rotated_at)
            .unwrap()
            .expect("rotates");
    }
    assert_eq!(last_used_at("device-grant"), Some(rotated_at));
    assert_eq!(last_used_at("code-grant"), None);
}
}
