Code Authorization Starter

Covers authorization-server-rust/src/domain/capabilities/oauth/code_authorization_starter.rs

The code authorization starter is what /oauth/authorize does once a browser that holds a browser session arrives carrying an app’s request; a browser without one is sent to pair before it gets here. It validates the request, parks it as a code request, and decides where the browser goes next. It also goes on with a request the browser has confirmed on its limited page.

Three questions about the parked request pick the next step:

  1. Does the browser’s session hold everything the request asks for? If not, and the session hasn’t gone on past the limited page for this app before, the request waits on that browser’s limited page, and nothing else is decided until the browser says to go on.
  2. Does a standing grant cover it? When the request makes no change to the app’s registration, a standing grant covers every scope it asks for, and a launch’s patient is the grant’s, the code is issued at once under the grant: the fast path. The Grant page has the whole rule.
  3. Can the browser decide it itself? Otherwise the request waits for a person. A session that may decide consents and holds the request’s approval scopes is sent to the consent card; any other browser goes to the wait page while the request is raised for the Owner.

The starter is public: no scope opens it, because the caller is the browser of whoever opened the app. Its powers are exactly two operations, start and continue_past_session_shortfall, each in one write scope. A request that would bother the Owner, by being raised for the Owner or parked for its limited page, first asks the authorization start limit, which the route hands in.

The tests start requests from the starter fixtures: by default a request whose session holds all the Owner holds, so it falls short of nothing, from a browser that can’t decide consents, and always admitted by the start limit.

start

Validate authorize_query (client and redirect first, then the redirectable params), park it, and decide: a fully pre-approved request is issued a code under the standing grant’s authority and sent back to the client; anything else waits on the Owner as a pending consent. It all happens in one write scope, so a refusal from inside it rolls everything back, a spent launch included; the Owner prompt is republished once that has committed.

The request is resolved against its client’s registration (ResolvedCodeRequest). A disabled client is refused. A fixed (server-defined) registration holds the request to its redirects and scopes. Any other client is trusted on first use: a request outside the registration is parked with a warning rather than rejected, never takes the fast path, and — while its redirect is untrusted — renders every failure locally rather than risk an open redirect.

A declared aud must be this server’s origin (its FHIR base). A launch must name an unconsumed, unexpired launch context minted for this client or for the server launcher; it is consumed (so it never works twice) and carried onto the parked request. Either failure is invalid_request, and its description says why: a client sees its own launch’s state (not recognized, already used, expired), and another app’s launch looks unknown. A request with no launch is plain OAuth. When the launch binds a patient, the fast path applies only if the standing grant names the same one; otherwise the Owner decides.

A request whose browser session holds less than it asks for (see session_shortfall) is parked, once validated, admitted by the start limit and its launch consumed, for its browser’s limited page (AuthorizeNextStep::ConfirmSessionShortfall); the fast path and the Owner wait for continue_past_session_shortfall. A session that has gone on past the page for this client before goes on as if it had again.

See AuthorizationStartError.

start_in

The order inside the scope is the point. Every check that can refuse the request runs first; the launch is consumed after them, so a refused request leaves its launch unspent; the request is parked last. The consume is consume_launch, which Launch Contexts explains with its refusals. The session’s shortfall is session_shortfall, and the standing grant’s coverage is GrantCoverage::resolve.

start’s flow, inside its write scope tx.

#![allow(unused)]
fn main() {
fn start_in<T: GrantTx>(
    &self,
    tx: &mut T,
    authorize_query: &AuthorizeRequest<'_>,
    ids: FreshIds,
    now: DateTime<Utc>,
) -> Result<Decided, AuthorizationStartError> {
    if !tx.has_active_signing_key()? {
        return Err(AuthorizationStartError::NoActiveSigningKey);
    }
    let maybe_existing_client = tx.client_by_id(authorize_query.client_id)?;
    let requested_redirect_uri = parse_redirect_uri(authorize_query.redirect_uri)?;
    let requested_scopes: Vec<String> = authorize_query
        .scope
        .split_whitespace()
        .map(str::to_string)
        .collect();
    let resolved = ResolvedCodeRequest::resolve(
        authorize_query.client_id,
        &requested_redirect_uri,
        &requested_scopes,
        maybe_existing_client.as_ref(),
    );
    if resolved.is_client_disabled() {
        return Err(AuthorizationStartError::LocalPage(
            AuthorizeRefusal::DisabledClient,
        ));
    }
    // A redirect is trustworthy only when a client we already know already
    // registered it.
    let redirect_trusted = resolved.is_redirect_registered();
    if resolved.is_registration_fixed() && !redirect_trusted {
        return Err(AuthorizationStartError::LocalPage(
            AuthorizeRefusal::RedirectUriNotAllowed,
        ));
    }
    validate_code_params(
        authorize_query,
        &requested_redirect_uri,
        redirect_trusted,
        &self.server_origin,
    )?;
    if resolved.is_registration_fixed() && !resolved.are_scopes_registered() {
        return Err(AuthorizationStartError::Redirectable {
            redirect_uri: Box::new(requested_redirect_uri),
            error: OAuthErrorCode::InvalidScope,
            description: SCOPES_NOT_REGISTERED_DESCRIPTION,
            client_state: authorize_query.client_state.to_owned(),
        });
    }
    let decidable_in_requesting_browser = authorize_query.can_decide_consents
        && resolved
            .approvable_scopes()
            .missing_approval_scopes(authorize_query.browser_session_grant)
            .is_empty();
    let coverage = GrantCoverage::resolve(
        tx,
        resolved.presented_client_change(),
        authorize_query.client_id,
        &requested_redirect_uri,
        &requested_scopes,
    )?;
    let waits_on_limited_page =
        !session_shortfall(&requested_scopes, authorize_query.browser_session_grant).is_empty()
            && !tx.is_session_shortfall_acknowledged_for_client(
                authorize_query.sid,

fn continue_in<T: GrantTx>(
    &self,
    tx: &mut T,
    id: &str,
    sid: &str,
    code: String,
    now: DateTime<Utc>,
) -> Result<Decided, AuthorizationStartError> {
    if !tx.has_active_signing_key()? {
        return Err(AuthorizationStartError::NoActiveSigningKey);
    }
    let parked_request = load_code_request_awaiting_limited_page(tx, id, sid, now)?;
    let maybe_existing_client = tx.client_by_id(&parked_request.client_id)?;
    let resolved = ResolvedCodeRequest::resolve(
        &parked_request.client_id,
        &parked_request.redirect_uri,
        &parked_request.requested_scopes,
        maybe_existing_client.as_ref(),
    );
    // The client was disabled since the request parked: the browser can't
    // go on with it, so it ends here, and the app hears why.
    if resolved.is_client_disabled() {
        return refuse_waiting_request(
            tx,
            &parked_request,
            AuthorizeRefusal::DisabledClient,
            now,
        );
    }
    let coverage = GrantCoverage::resolve(
        tx,
        resolved.presented_client_change(),
        &parked_request.client_id,
        &parked_request.redirect_uri,
        &parked_request.requested_scopes,
    )?;
    decide(
        tx,
        &parked_request,
        coverage,
        // The request spent from the start limit when it parked.
        &|| true,
        code,
        now,
        |tx| {
            let not_found = || {
                AuthorizationStartError::Store(
                    AuthorizationServerError::AuthorizationRequestNotFound {
                        id: id.to_owned(),
                    },
                )
            };

                .map_err(|_| not_found())?;
            if !tx.replace_code_request(&parked_request, &continued)? {

fn main() {
fn decide<T: GrantTx>(
    tx: &mut T,
    request: &CodeRequest,
    coverage: GrantCoverage,
    may_raise_for_owner: &dyn Fn() -> bool,
    code: String,
    now: DateTime<Utc>,
    park: impl FnOnce(&mut T) -> Result<CodeRequest, AuthorizationStartError>,
) -> Result<Decided, AuthorizationStartError> {
    let decidable_in_requesting_browser = request.decidable_in_requesting_browser;
    // The fast path: the standing grant is the authority, as long as its
    // patient is one the launch admits.
    let fast_path_coverage = match coverage {
        GrantCoverage::Full(standing_grant_coverage)
            if request.admits_patient(standing_grant_coverage.patient()) =>
        {
            Some(standing_grant_coverage)
        }
        _ => None,
    };
    // A request about to be raised for the Owner asks the start limit first.
    if fast_path_coverage.is_none() && !decidable_in_requesting_browser && !may_raise_for_owner() {
        return Err(AuthorizationStartError::StartLimited);
    }

    let parked_request = park(tx)?;

    let next_step = match fast_path_coverage {
        Some(standing_grant_coverage) => {
            issue_under_standing_grant(tx, &standing_grant_coverage, &parked_request, code, now)?
        }
        None => Ok(AuthorizeNextStep::AwaitOwner {
            request_id: parked_request.id.clone(),
            decidable_in_requesting_browser,
        }),
    };
    // A request raised for the Owner is newly pending; one the fast path
    // decided may have been the Owner prompt for the width of the approval,
    // so the prompt is recomputed either way.
    Ok(Decided {
        next_step,
        pending_consents_changed: true,
    })
}

fn main() {
fn issue_under_standing_grant(
    tx: &mut impl GrantTx,
    standing_grant_coverage: &StandingGrantCoverage,
    parked_request: &CodeRequest,
    code: String,
    now: DateTime<Utc>,
) -> Result<Result<AuthorizeNextStep, AuthorizationStartError>, AuthorizationStartError> {
    let requested_redirect_uri = parked_request.redirect_uri.clone();
    let client_state = &parked_request.client_state;
    match RequestApprover::within(tx).approve_for_code(
        CodeAuthority::StandingGrant(standing_grant_coverage),
        parked_request,
        standing_grant_coverage.patient(),

        CodeApproval::Issued(issued_code) => Ok(Ok(AuthorizeNextStep::RedirectToClient {

        CodeApproval::BrowserSessionEnded => Ok(Err(AuthorizationStartError::Redirectable {
            redirect_uri: Box::new(requested_redirect_uri),
            error: OAuthErrorCode::AccessDenied,

fn validate_code_params(
    authorize_query: &AuthorizeRequest<'_>,
    redirect_uri: &Url,
    redirect_trusted: bool,
    server_origin: &str,
) -> Result<(), AuthorizationStartError> {
    let fail = |error: OAuthErrorCode, local: AuthorizeRefusal| {
        start_error(
            authorize_query,
            redirect_uri,
            redirect_trusted,
            error,
            local,
        )
    };
    // Only the authorization-code grant is implemented (RFC 6749 §4.1.2.1).
    if authorize_query.response_type != "code" {
        return Err(fail(
            OAuthErrorCode::UnsupportedResponseType,
            AuthorizeRefusal::UnsupportedResponseType,
        ));
    }
    // Only S256 PKCE is supported; anything else is `invalid_request` (RFC
    // 7636 §4.4.1), as is a malformed challenge.
    if authorize_query.code_challenge_method != "S256" {
        return Err(fail(
            OAuthErrorCode::InvalidRequest,
            AuthorizeRefusal::UnsupportedCodeChallengeMethod,
        ));
    }
    if !is_valid_s256_code_challenge(authorize_query.code_challenge) {
        return Err(fail(
            OAuthErrorCode::InvalidRequest,
            AuthorizeRefusal::InvalidCodeChallenge,
        ));
    }
    // A declared SMART `aud` must name this server.
    if let Some(aud) = authorize_query.aud {
        // The server's origin is also its FHIR base, the `iss` every launch
        // hands the app, so a SMART `aud` names this server exactly when it is
        // that origin.
        if aud != server_origin {
            return Err(fail(
                OAuthErrorCode::InvalidRequest,
                AuthorizeRefusal::InvalidAudience,
            ));
        }
    }
    Ok(())
