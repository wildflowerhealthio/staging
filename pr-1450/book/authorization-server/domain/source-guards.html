Wildflower, Read in Order

Source Guards

Covers authorization-server-rust/src/domain/mod.rs

Some of the crate’s rules are about where code may be written, not what it does. A route handler never reaches the store except through a capability. A privileged write never happens outside a writer. The domain never imports the transport layer. The compiler can’t hold those, so source-guard tests do: each enumerates the source files and fails on a line that breaks the rule, so a new file is guarded the day it is added.

They are advisory-strength, and say so. The needles are text, not types: a guard catches the ordinary way of breaking its rule, not a determined one. What keeps them honest is that they scan production code only. Comments and string literals may name anything, and every #[cfg(test)] item (the unit-test module, a test-only method, a test-only use) may arrange state directly, planting rows or building proofs, without being the production path the guard pins.

The domain module

src/domain/mod.rs is also the domain’s front page. Nothing in the domain depends on crate::http. The entities carry diesel derives naming their crate::db tables, and that is the domain’s only reach into the adapter.

  • The entities, one module each, own their rules. An authorization request owns its lifecycle: each change is a transition, and the store writes it back only while the row still has the status it was read with.
  • The port, the grant store, is persistence as the domain sees it: one scope per operation, read or write, handing out single-statement primitives, one trait per table.
  • The capabilities are the operations. Each opens its one scope at its top, runs its flow inside to an outcome, and acts on the outcome (republishing, the revocation store) once the scope has closed (Capabilities).
  • The authority proofs are what every privileged write demands (Authority), and the writers are the one place those writes happen (Writers).

Everything fails with the domain’s own AuthorizationServerError.

The guards

Two guards sit here, and three more beside the layers they guard:

  • production_code_precedes_the_test_module: no file under src/ has production code after its unit-test module.
  • domain_never_references_crate_http: no file under src/domain/ names crate::http.
  • source_guards::handlers_reach_the_state_only_through_capabilities: no route handler names the router state or one of its fields; it reaches them only through a capability extractor (Capabilities).
  • source_guards::middleware_verifies_only_through_the_token_verifier: no middleware names the store or the revocation store; the gates verify a token through the token verifier.
  • tests::privileged_store_calls_happen_only_in_writers: the calls that grant authority, and the building of an approved or claimed request, appear only in the writers and the few files allowed them (Writers).

The handler, middleware and writer guards also fail when they find fewer files than expected, so a moved directory can’t make them pass by scanning nothing.

production_lines

The lines a guard scans.

The production code of a source file, one entry per line that has any, numbered from 1. A guard scans these: comments and string literals may name anything (they are blanked out, so a trailing // … never trips a needle), and every #[cfg(test)]-gated item — the unit-test module, a test-only helper method, a test-only use — may arrange state directly (planting rows, constructing proofs) without being the production path the guard exists to pin. Only the gated item itself is skipped, so production code after it is still scanned.

#![allow(unused)]
fn main() {
pub(crate) fn production_lines(source: &str) -> Vec<(usize, String)> {
    let code = code_only(source);
    let test_items = cfg_test_items(&code);
    code.iter()
        .enumerate()
        .filter(|(i, _)| !test_items.iter().any(|item| item.lines.contains(i)))
        .filter(|(_, line)| !line.trim().is_empty())
        .map(|(i, line)| (i + 1, line.clone()))
        .collect()
}
}

production_code_after_test_module

The line (numbered from 1) of the first production code after the file’s inline unit-test module (#[cfg(test)] mod … { … }), or None when the test module comes last. Production code belongs above the tests, so a reader who reaches the test module has seen the whole implementation. A braceless #[cfg(test)] mod x; is not an inline module, and a second gated module after the first is test code, not production.

#![allow(unused)]
fn main() {
pub(crate) fn production_code_after_test_module(source: &str) -> Option<usize> {
    let code = code_only(source);
    let test_items = cfg_test_items(&code);
    let first_module_end = test_items
        .iter()
        .find(|item| item.is_inline_module)?
        .lines
        .end;
    (first_module_end..code.len())
        .filter(|i| !test_items.iter().any(|item| item.lines.contains(i)))
        .find(|&i| !code[i].trim().is_empty())
        .map(|i| i + 1)
}
}

cfg_test_items

Every #[cfg(test)]-gated item in code (the output of code_only, so braces inside comments and strings are already gone).

#![allow(unused)]
fn main() {
fn cfg_test_items(code: &[String]) -> Vec<CfgTestItem> {
    let mut items = Vec::new();
    let mut i = 0;
    while i < code.len() {
        if code[i].trim() != "#[cfg(test)]" {
            i += 1;
            continue;
        }
        let start = i;
        // Skip any further attributes and blank lines to the item itself.
        let mut item_start = i + 1;
        while item_start < code.len() {
            let trimmed = code[item_start].trim();
            if trimmed.is_empty() || trimmed.starts_with("#[") {
                item_start += 1;
            } else {
                break;
            }
        }
        let end = item_end(code, item_start);
        let is_inline_module = code
            .get(item_start)
            .is_some_and(|line| is_mod_header(line) && line.contains('{'));
        items.push(CfgTestItem {
            lines: start..end,
            is_inline_module,
        });
        i = end;
    }
    items
}
}

item_end

The line after the item that starts at start: the line where its braces balance again, or — for a braceless item (use …;, mod x;) — the line holding its terminating ;.

#![allow(unused)]
fn main() {
fn item_end(code: &[String], start: usize) -> usize {
    let mut depth: usize = 0;
    let mut opened = false;
    for (i, line) in code.iter().enumerate().skip(start) {
        for ch in line.chars() {
            match ch {
                '{' => {
                    depth += 1;
                    opened = true;
                }
                '}' => depth = depth.saturating_sub(1),
                ';' if !opened => return i + 1,
                _ => {}
            }
        }
        if opened && depth == 0 {
            return i + 1;
        }
    }
    code.len()
}
}

is_mod_header

Whether line opens a module declaration (mod x, pub mod x, pub(crate) mod x, …).

#![allow(unused)]
fn main() {
fn is_mod_header(line: &str) -> bool {
    let trimmed = line.trim_start();
    let after_visibility = if let Some(rest) = trimmed.strip_prefix("pub") {
        let rest = rest.trim_start();
        match rest.strip_prefix('(') {
            Some(scoped) => scoped.split_once(')').map_or(rest, |(_, after)| after),
            None => rest,
        }
    } else {
        trimmed
    };
    after_visibility.trim_start().starts_with("mod ")
}
}

code_only

source, line for line, with every comment and every string / char literal replaced by spaces, so what remains is code alone. Handles line and (nested) block comments, escaped and raw strings (r#"…"#, byte variants), and tells a char literal ('{') from a lifetime ('a). Line numbers still match the file, and blanking literals also blanks the braces inside them, which keeps cfg_test_items’ brace count true.

#![allow(unused)]
fn main() {
pub(crate) fn code_only(source: &str) -> Vec<String> {
    let chars: Vec<char> = source.chars().collect();
    let mut out = String::with_capacity(source.len());
    let mut i = 0;
    let blank = |c: char| if c == '\n' { '\n' } else { ' ' };
    while i < chars.len() {
        let c = chars[i];
        let next = chars.get(i + 1).copied();
        if c == '/' && next == Some('/') {
            while i < chars.len() && chars[i] != '\n' {
                out.push(' ');
                i += 1;
            }
        } else if c == '/' && next == Some('*') {
            let mut depth = 0;
            while i < chars.len() {
                if chars[i] == '/' && chars.get(i + 1) == Some(&'*') {
                    depth += 1;
                    out.push_str("  ");
                    i += 2;
                } else if chars[i] == '*' && chars.get(i + 1) == Some(&'/') {
                    depth -= 1;
                    out.push_str("  ");
                    i += 2;
                    if depth == 0 {
                        break;
                    }
                } else {
                    out.push(blank(chars[i]));
                    i += 1;
                }
            }
        } else if let Some(hashes) = raw_string_hashes(&chars, i) {
            // `r`/`br`, the hashes, the opening quote, then up to the
            // closing quote followed by as many hashes.
            let mut j = i;
            while chars[j] != '"' {
                j += 1;
            }
            j += 1;
            let closing: Vec<char> = std::iter::once('"')
                .chain(std::iter::repeat_n('#', hashes))
                .collect();
            while j < chars.len() && !chars[j..].starts_with(&closing) {
                j += 1;
            }
            let end = (j + closing.len()).min(chars.len());
            out.extend(chars[i..end].iter().map(|&c| blank(c)));
            i = end;
        } else if c == '"' {
            out.push(' ');
            i += 1;
            while i < chars.len() && chars[i] != '"' {
                if chars[i] == '\\' {
                    out.push(' ');
                    i += 1;
                }
                if let Some(&escaped) = chars.get(i) {
                    out.push(blank(escaped));
                }
                i += 1;
            }
            out.push(' ');
            i += 1;
        } else if c == '\'' {
            // A char literal is `'x'` or `'\…'`; anything else is a lifetime.
            let literal_len = match next {
                // Past the escaped char, so `'\''` closes on its last quote.
                Some('\\') => chars
                    .get(i + 3..)
                    .and_then(|rest| rest.iter().position(|&c| c == '\''))
                    .map(|close| close + 4),
                Some(_) if chars.get(i + 2) == Some(&'\'') => Some(3),
                _ => None,
            };
            match literal_len {
                Some(len) => {
                    out.extend(std::iter::repeat_n(' ', len));
                    i += len;
                }
                None => {
                    out.push(c);
                    i += 1;
                }
            }
        } else {
            out.push(c);
            i += 1;
        }
    }
    out.lines().map(str::to_owned).collect()
}
}

raw_string_hashes

The number of #s when a raw string literal (r"…", r#"…"#, br#"…"#) starts at i, else None. An identifier that merely ends in r (for, bar#) is not a raw string.

#![allow(unused)]
fn main() {
fn raw_string_hashes(chars: &[char], i: usize) -> Option<usize> {
    let prefix_len = match (chars.get(i), chars.get(i + 1)) {
        (Some('r'), _) => 1,
        (Some('b'), Some('r')) => 2,
        _ => return None,
    };
    let preceded_by_ident = i
        .checked_sub(1)
        .and_then(|p| chars.get(p))
        .is_some_and(|&p| p.is_alphanumeric() || p == '_');
    if preceded_by_ident {
        return None;
    }
    let hashes = chars[i + prefix_len..]
        .iter()
        .take_while(|&&c| c == '#')
        .count();
    (chars.get(i + prefix_len + hashes) == Some(&'"')).then_some(hashes)
}
}

production_code_precedes_the_test_module

Production code goes above the unit-test module: a reader (or a reviewer) who reaches #[cfg(test)] mod tests has then seen the whole implementation. This test enumerates src/ and fails on any file with production code after its test module, reporting every violation at once as path:line.

#![allow(unused)]
fn main() {
fn production_code_precedes_the_test_module() {
    let src = std::path::Path::new(concat!(env!("CARGO_MANIFEST_DIR"), "/src"));
    let mut violations = Vec::new();
    for path in rs_files_under(src).expect("enumerate src") {
        let relative = relative_to(&path, src).expect("enumerated under src");
        let source =
            std::fs::read_to_string(&path).unwrap_or_else(|e| panic!("read {relative}: {e}"));
        if let Some(line) = production_code_after_test_module(&source) {
            violations.push(format!("{relative}:{line}"));
        }
    }
    assert!(
        violations.is_empty(),
        "production code after the unit-test module (move it above the tests): {violations:?}",
    );
}
}

domain_never_references_crate_http

The guard’s needle is assembled from parts, so its own source doesn’t trip it.

domain/ must never depend on crate::http — the capabilities live here and are built from crate::live_bindings, so a stray use crate::http::… would re-couple the domain to the transport layer. This test enumerates the domain/ tree and fails if any non-comment line names crate::http, so the invariant can’t silently regress.

#![allow(unused)]
fn main() {
fn domain_never_references_crate_http() {
    // Assembled from parts so this guard's own source doesn't contain the
    // literal it scans for (which would make it flag itself).
    let needle = concat!("crate", "::", "http");
    let domain_dir = std::path::Path::new(concat!(env!("CARGO_MANIFEST_DIR"), "/src/domain"));
    for path in rs_files_under(domain_dir).expect("enumerate domain_dir") {
        let source = std::fs::read_to_string(&path)
            .unwrap_or_else(|e| panic!("read {}: {e}", path.display()));
        for (n, line) in production_lines(&source) {
            assert!(
                !line.contains(needle),
                "domain/ file {} line {n} imports the transport layer (`{needle}`) — domain \
                 must stay transport-free; route the dependency through a port or `crate::live_bindings`",
                path.display(),
            );
        }
    }
}
}
