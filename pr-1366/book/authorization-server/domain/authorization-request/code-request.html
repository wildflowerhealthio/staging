Code Request

Covers authorization-server-rust/src/domain/authorization_request/code/mod.rs

Covers authorization-server-rust/src/domain/authorization_request/code/resolved.rs

A code request is an app’s request for an authorization code (RFC 6749 §4.1), parked by /oauth/authorize until it is decided. It is always made in a browser session: /oauth/authorize sends a browser without one to sign in or pair first. The code it earns is issued under that session, not the approver’s, and carries only what that session also covers.

stateDiagram-v2
    [*] --> AwaitingLimitedPage: new, the session falls short
    [*] --> Pending: new
    AwaitingLimitedPage --> Pending: acknowledge_session_shortfall (Continue)
    AwaitingLimitedPage --> Denied: deny_on_limited_page (Cancel)
    Pending --> Pending: raise_for_owner
    Pending --> Approved: approve
    Pending --> Denied: deny

The limited page

Suppose the browser’s session lacks a scope the app asks for: a laptop paired read-only, an app that wants write. The request starts awaiting the limited page, and the browser is sent there. The page says what’s missing and offers Continue or Cancel. Until the browser goes on, the Owner isn’t asked about the request and nothing decides it. Continue makes it pending with a fresh lifetime; Cancel denies it. Once a browser has pressed Continue for an app, its later requests for that app start pending: the page is shown once per browser per app. Both buttons are transitions read from the same status, so of two tabs pressing them at once only the first lands (the guarded replace).

Who decides

A pending request is decided by the Owner, or by the browser that made it when that browser’s session may decide consents and holds what approving takes: then the browser shows the consent card itself. A browser that can read the request but not approve it can raise it for the Owner, after which the host notifies the Owner about it. When a standing grant covers the request, nobody decides: the request is parked and approved at once.

Resolving against the registration

Every step that judges a code request, /oauth/authorize, the limited page’s Continue, and the consent read and approval, learns what the app’s client row says about it in one place: a resolved code request. It is worked out from the row as it stands on every read, never stored, so a consent prompt opened after the row moved shows the move. The most an approval may grant comes from ApprovableScopes::for_code, which caps a fixed registration at itself.

CodeRequest

An authorization-code request, from /oauth/authorize to its decision. Started by new and changed only by its transitions, each of which answers with the changed request for the store’s guarded replace.

#![allow(unused)]
fn main() {
pub struct CodeRequest {
    /// An internal UUID: the `$id` of the wait page, the consent card and the
    /// limited page.
    pub id: String,
    /// The client that made the request.
    pub client_id: String,
    /// The scopes the client asked for.
    pub requested_scopes: Vec<String>,
    /// When the request started.
    pub requested_at: DateTime<Utc>,
    /// The instant the request stops waiting for a decision. Going on past
    /// the limited page restarts it.
    pub expires_at: DateTime<Utc>,
    /// Where the request stands.
    pub state: CodeRequestState,
    /// The redirect the client presented; its code or error goes back there.
    pub redirect_uri: Url,
    /// The PKCE S256 challenge (RFC 7636); `plain` is refused at the
    /// boundary, so the method is always S256.
    pub code_challenge: String,
    /// The `state` the client sent, which its callback carries back.
    pub client_state: String,
    /// The browser session the request was made in, which the code it earns
    /// is issued under: this session, not the approver's. `/oauth/authorize`
    /// sends a browser without one to pairing first.
    pub sid: String,
    /// The SMART App Launch `launch` value the request consumed, or `None`
    /// for a plain OAuth request.
    pub launch: Option<String>,
    /// The patient the consumed launch binds, if any. An approval must name
    /// this patient ([`CodeRequest::admits_patient`]).
    pub launch_bound_patient: Option<String>,
    /// The requested scopes a standing grant already covered when it parked;
    /// the consent card shows them ticked.
    pub pre_approved_scopes: Vec<String>,
    /// Whether the request can be decided in the browser that made it: that
    /// browser's session can decide consents and holds the request's approval
    /// scopes, so it shows the consent card itself. Raising the request for
    /// the Owner clears it.
    pub decidable_in_requesting_browser: bool,
}
}

resolve

Resolve a request from client_id presenting redirect_uri and requested_scopes against the client’s row maybe_existing_client.

#![allow(unused)]
fn main() {
pub(crate) fn resolve(
    client_id: &str,
    redirect_uri: &Url,
    requested_scopes: &[String],
    maybe_existing_client: Option<&Client>,
) -> Self {
    match maybe_existing_client {
        // Trusted on first use: an unknown client is named by its
        // `client_id`, and approving its request would create its row.
        None => ResolvedCodeRequest {
            client_name: client_id.to_owned(),
            client_disabled: false,
            registration_is_fixed: false,
            redirect_is_registered: false,
            presented_client_change: PresentedClientChange::WouldCreate,
            approvable_scopes: ApprovableScopes::for_code(requested_scopes, None, false),
        },
        Some(existing_client) => {
            let registration_is_fixed = existing_client.is_registration_fixed();
            ResolvedCodeRequest {
                client_name: existing_client.name.clone(),
                client_disabled: existing_client.disabled_at.is_some(),
                registration_is_fixed,
                redirect_is_registered: existing_client.allows_redirect_uri(redirect_uri),
                presented_client_change: PresentedClientChange::from_presented_registration(
                    &PresentedClientRegistration {
                        maybe_existing_client: Some(existing_client),
                        redirect_uri,
                        scopes: requested_scopes,
                    },
                ),
                approvable_scopes: ApprovableScopes::for_code(
                    requested_scopes,
                    Some(existing_client),
                    registration_is_fixed,
                ),
            }
        }
    }
}
}

pub(crate) fn are_scopes_registered(&self) -> bool {
    match &self.presented_client_change {
        PresentedClientChange::NoChange => true,
        PresentedClientChange::WouldCreate => false,
        PresentedClientChange::WouldWiden {
            unregistered_requested_scopes,
            ..
        } => unregistered_requested_scopes.is_empty(),
    }
}
}
