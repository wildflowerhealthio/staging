Wildflower, Read in Order

Clients

Covers authorization-server-rust/src/domain/capabilities/access/clients.rs

The Owner’s “Trusted apps” list is every registered client, with a switch to disable each. A disabled app gets nothing: /oauth/authorize and /oauth/token refuse it, and its waiting code requests are neither shown nor approved. Disabling writes one column, disabled_at, so re-enabling brings the app back exactly as it was registered. Disabling and re-enabling both edit the row in place, so both take wildflower/Client.u.

The two essential clients are how the Owner gets in, so an essential app can’t be disabled, and the list offers no switch for it. Re-enabling one is allowed, so an essential app disabled by hand in the database can still be recovered.

set_disabled_at

The tests disable and enable through the disabler fixtures, each disable stamped at a fixed second unless the test says otherwise. The property test runs any sequence of steps over two registered apps and one id never registered.

Set client_id’s disabled_at in one write scope and return the row as stored.

  • Some(stamp) disables the client, stamped stamp. The handler passes the server’s own now whatever time was sent, so a disable can’t be scheduled or backdated. A client that already carries a stamp keeps it, so a repeated disable doesn’t move the time, and a write that would change nothing is skipped.
  • None re-enables the client. Its registration (redirects, scopes, secret) is untouched by the round trip.
Errors

AuthorizationServerError::ClientNotFound when no such client exists. Disabling an essential client is AuthorizationServerError::EssentialClient (see is_essential_client), refused before anything is read. Re-enabling one stays allowed, so an essential client disabled out of band (direct SQL) can still be recovered.

#![allow(unused)]
fn main() {
pub(crate) fn set_disabled_at(
    &self,
    client_id: &str,
    stamp: Option<DateTime<Utc>>,
) -> Result<ClientView, AuthorizationServerError> {
    let essential = is_essential_client(client_id);
    if essential && stamp.is_some() {
        return Err(AuthorizationServerError::EssentialClient {
            client_id: client_id.to_owned(),
        });
    }
    let not_found = || AuthorizationServerError::ClientNotFound {
        client_id: client_id.to_owned(),
    };
    // One write scope, so two concurrent disables serialise at the read
    // and the second sees (and keeps) the first one's stamp.
    let client = self.store.write(|tx| {
        let client = tx.client_by_id(client_id)?.ok_or_else(not_found)?;
        let disabled_at = stamp.map(|stamp| client.disabled_at.unwrap_or(stamp));
        if disabled_at == client.disabled_at {
            return Ok(client);
        }
        if tx.set_client_disabled(client_id, disabled_at)? {
            Ok(Client {
                disabled_at,
                ..client
            })
        } else {
            Err(not_found())
        }
    })?;
    Ok(ClientView { client, essential })
}
}

authorization-server-rust/src/domain/capabilities/access/clients.rs lines 299–325 · authorization-server in the code index

Any sequence of disables and enables — each step an index into IDS and the stamp to disable with (None enables) — leaves each client’s disabled_at equal to a simple model: the stamp of the first disable since the last enable, or None. No step touches any other field or creates a row. Each step returns the row as stored; every step naming the unregistered id is ClientNotFound.

#![allow(unused)]
fn main() {
fn disable_and_enable_match_the_model(
    steps in prop::collection::vec(
        (0..IDS.len(), prop::option::of(0..10_000i64)),
        0..24,
    ),
) {
    let registered = [client(IDS[0], &["openid"]), client(IDS[1], &["patient/*.rs"])];
    let disabler = disabler_with(&registered);
    let mut model: [Option<DateTime<Utc>>; 2] = [None, None];

    for (index, stamp) in steps {
        if let Some(slot) = model.get_mut(index) {
            *slot = stamp.map(|stamp| slot.unwrap_or(at(stamp)));
        }
        let result = disabler.set_disabled_at(IDS[index], stamp.map(at));
        match (registered.get(index), model.get(index)) {
            (Some(row), Some(&disabled_at)) => {
                let expected = ClientView {
                    client: Client { disabled_at, ..row.clone() },
                    essential: false,
                };
                prop_assert_eq!(result, Ok(expected));
            }
            _ => {
                let not_found = AuthorizationServerError::ClientNotFound { client_id: IDS[index].to_owned() };
                prop_assert_eq!(result, Err(not_found));
            }
        }
    }

    for (row, disabled_at) in registered.iter().zip(model) {
        prop_assert_eq!(stored(&disabler, &row.client_id), Client { disabled_at, ..row.clone() });
    }
    prop_assert_eq!(disabler.store.tx().list_clients().unwrap().len(), registered.len());
}
}
